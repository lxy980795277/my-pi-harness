读取仓库规则、Git状态、分支和实际diff，确认工作区与远端。确定本次纳入范围，保留用户无关改动；修改文件清单不能代替审查diff。

按仓库要求完成检查、版本及记录。检查意外删除、生成产物和秘密泄露风险，不读取任务无关凭据。提交信息和PR描述围绕最终行为、原因和实际验证撰写。

通过当前可用的本地Git或已加载MCP执行用户要求的动作。提交授权不自动包含推送、合并或发布。历史重写与破坏性分支操作需明确授权，远端变化时先核对。

远端写入结果未知时停止并查询结果，不盲目重复创建。完成后返回实际commit、分支和PR链接；准备好的描述与本地测试不能作为已经发布的证据。

## 已连接服务的只读访问

当前激活Skill记录中的gatewayUrl是本机只读入口。使用web_fetch GET请求该入口下的服务API路径；宿主附加认证，不传入认证头，也不读取凭据。网关拒绝的路径不能绕过或改为上游直连。修改操作通过tool_search搜索已启用的MCP工具；命中会自动加载，下一次模型请求按返回的真实名称调用，继续遵守用户授权和工具审批。
