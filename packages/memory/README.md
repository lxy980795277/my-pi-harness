# 长期记忆领域

本包拥有独立记忆的人工与Agent直接写入、CAS/幂等请求、使用与自动学习设置、合法候选快照与固定/相关选择。SQL事务由storage适配，认证与scope解析由daemon完成；本包不访问HTTP、Pi、模型Worker或界面。

`MemoryService.snapshot`在同一读取事务取得固定正文、全部合法候选的ID/revision/方式/启停元数据及设置，指纹包含未命中项与新增项。异步检索后只接受该快照中仍匹配的条目；最终派发由runtime同步调用`isCurrent`复核，不在复核中计算向量。

`selection.ts`只在宿主完成本地相关性复核且概率分数至少为0.5时采用相关项，最多八条，并记录有界遗漏解释。词法命中和向量相似度只用于候选检索，不能代替相关性复核；模型未准备、检查失败或输入超限而没有完整分数的候选标为未核验。固定正文不按相关性裁掉；runtime按实际模型窗口先容纳固定项，再为相关项分配剩余额度。相关检索可以为零，工具搜索候选不直接成为自动采用事实。

`snapshot`叶出口只提供纯记忆JSON编解码，供最终prompt与历史日志范围复用。正文只保留在请求的一个JSON块；候选/未采用说明是没有正文的宿主元数据。历史采用与当前事实分开读取，遗忘不重写已经交出的历史请求。

管理读取分页，精确状态和正文读取有界。storage负责独立事实、来源复核、遗忘及最小receipt；Session投影恢复不能清除这些事实。固定容量限制与相关记忆总量分开，不用旧owner总数限制截断候选集。

`saveFromAgent`、`learnFromAgent`、`updateFromAgent`与`deleteFromAgent`直接修改独立事实。`mutations.ts`统一正文归一化和默认采用方式：显式保存默认固定，自动学习的事实默认相关、偏好与指令默认固定；更新省略方式时保留原值。使用与自动学习默认开启，`learnFromAgent`在写入事务内重新检查两项设置，显式保存不依赖自动学习开关。

storage复核当前根Run、实际消费的直接用户消息、精确正文hash和真实工具参数。工具意图必须晚于其实际消费的输入，子任务不能写入。混入搜索引用的输入不能作为自动学习证据，显式保存仍可处理这些输入。没有待确认提案、一次性学习授权或动作有效期。

同scope、类别与归一化正文的精确重复，仅在既有事实启用且采用方式一致时复用；已停用或方式不同时明确冲突，保留人工状态并要求显式修改。每个真实工具ID各有最小幂等receipt，并记录新增来源指纹。来源修正与重复写入只累积来源指纹；遗忘抑制这些来源的迟到写入，不保存正文版本史。旧工具重试只返回已提交receipt，遗忘后不复活。既有独立事实的人工纠正与遗忘不依赖历史来源仍然可读。画像复用启用条目的scope、类别与分页查询，不保存另一份总结正文。
