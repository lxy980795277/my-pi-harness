# 工作区导航密度与图标

## Spec

状态：既有导航与向右展开已验证；按用户最新要求移除工作区路径tooltip，保留紧凑选项和菜单布局，移除调整已实现并完成本机验证。证据见[verify](verify.md)。属于M2工作区导航的后续交互优化，不扩大M3/M4范围，不提交或推送。

### Roadmap Alignment

对照[roadmap](../../00_OVERVIEW/roadmap.md)，沿用M2工作区管理与侧栏交互，保持M3及后续里程碑的功能归属。仅调整客户端导航与既有管理操作，不增加协议或数据库迁移。

### Intent

工作区默认按展开状态显示蓝色打开/关闭文件夹，悬停时原位替换成展开/收起箭头。目录和会话背景占满可用宽度，hover即时响应；工作区右侧悬浮更多与加号，用户明确点击加号才进入该工作区的新对话。

### Constraints

- 图标共用固定16px位置；标题按钮仅键盘focus-visible显示箭头，鼠标点击后的普通focus不得阻止移出后恢复文件夹。悬停范围仅工作区标题行，不延伸到子会话。
- 文件夹蓝色由浅深主题语义token拥有，箭头使用普通操作颜色。
- 目录主按钮只展开/收起，不切页面、会话或新对话的工作区选择。新对话加号组合既有导航动作，回到输入首页并预选所属工作区，不直接创建空Session，不将工作区名称写入消息正文。
- 工作区主行占满侧栏可用宽度；更多和加号在行内右侧绝对定位，不挤占主按钮宽度，标题可截断并为悬浮操作留出安全内边距。hover/focus和弹层打开时操作可见，工作区/会话及其操作按钮都不保留hover过渡动画。
- 更多弹层仅有带图标的“重命名”和“删除”，分别复用现有编辑和移除确认流程；选择动作关闭弹层，不触发目录展开或创建。编辑保存不切换当前新对话目标；删除仍只移除登记，不能绕过存在未归档会话时的服务端限制或删除文件。
- 使用已有shadcn组件与Lucide图标；未分配工作区是合成组，不提供注册工作区的编辑/删除操作。焦点和键盘操作保留，避免隐藏动作仍在不可见时接收鼠标点击。
- 只做相关类型、静态和页面检查，不新增样式镜像测试或重复全套打包。
- 工作区选择项只显示目录图标和名称，悬停或键盘聚焦不展示路径tooltip，输入栏的工作区选择也不保留原生title路径提示。基础Select的现有描述项与键盘选择保持可用；仅为该功能引入的无调用组件和依赖一并移除。
- 同类下拉默认从触发器下方开始边对齐，向右展开；视口边缘保留碰撞避让。工作区更多、附件添加、图标选择及各类Select采用一致的默认对齐。

### Acceptance Criteria

- AC-01：默认按展开状态显示蓝色打开/关闭文件夹；标题行hover或标题按钮键盘focus-visible时显示同尺寸箭头，鼠标点击展开/收起并移出后恢复文件夹，标题不位移。
- AC-02：会话行背景与目录行外侧对齐，标题文字与目录名称起点对齐；无树形竖线，行高32px，时间仍可见。
- AC-03：目录仍可收起/展开，选中会话与管理操作可用。
- AC-04：工作区主按钮背景整行铺满，右侧悬浮更多/加号，不因显示/隐藏操作改变宽度；hover无transition，标题不会覆盖操作。
- AC-05：已有会话或运行状态页点击目录仅展开收起，当前页面和选择保持；点击加号才回到新对话，正确预选工作区，发送前没有新增Session。
- AC-06：更多打开紧凑下拉弹层，重命名真实保存且刷新保留；删除显示确认并遵守既有约束，文件不删除，操作不触发新对话。
- AC-07：工作区选项只有图标与名称，悬停和键盘聚焦均不弹路径提示；选择后触发器仍只显示名称且无原生title，键盘选择不回归。
- AC-08：工作区更多与同类下拉在空间足够时从触发器开始边向右展开；视口边缘仍能完整操作。

## UseCase

鼠标移入和离开目录行、用键盘聚焦及切换展开状态，检查图标替换和文字位置；打开已有对话，检查整行背景、紧凑高度与创建时间。

从一个已有对话展开/收起另一个工作区，保持原对话；进入运行状态后点击目录仍保持该页。明确点击工作区加号，返回新对话并选中该工作区，输入和发送前没有空会话。更多中重命名后刷新检查，删除空工作区经确认移除登记并保留目录文件；有会话的工作区仍按服务端规则拒绝移除。

## Issues

原目录同时展示12px箭头与16px文件夹；会话容器有左侧缩进和竖线，占用侧栏阅读宽度。

用户反馈：移除容器缩进后还需保留会话内部padding，保证文字与目录名称对齐；group-focus-within让鼠标点击留下的焦点持续显示箭头，应限制为标题按钮的键盘focus-visible。

后续反馈：原编辑/移除按钮位于flex流中，即使opacity为0仍占宽，使目录背景变窄；标题绑定工作区选择会隐式改变新对话目标。改为整行背景、绝对定位动作，以及标题纯展开/加号明确新建。
