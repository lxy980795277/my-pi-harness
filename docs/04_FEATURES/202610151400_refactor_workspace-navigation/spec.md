# 工作区导航密度与图标

## Spec

状态：文字对齐和鼠标点击后图标滞留已修复并完成针对性检查，待用户查看；不提交或推送。

### Intent

工作区默认按展开状态显示蓝色打开/关闭文件夹，悬停时原位替换成展开/收起箭头；会话背景占满可用宽度，内部左侧padding使标题与目录名称对齐，目录与会话行更紧凑。

### Constraints

- 图标共用固定16px位置；标题按钮仅键盘focus-visible显示箭头，鼠标点击后的普通focus不得阻止移出后恢复文件夹。悬停范围仅工作区标题行，不延伸到子会话。
- 文件夹蓝色由浅深主题语义token拥有，箭头使用普通操作颜色。
- 保留目录展开/选择、会话创建时间、选中态及管理动作，仅改变布局和视觉密度。
- 只做相关类型、静态和页面检查，不新增样式镜像测试或重复全套打包。

### Acceptance Criteria

- AC-01：默认按展开状态显示蓝色打开/关闭文件夹；标题行hover或标题按钮键盘focus-visible时显示同尺寸箭头，鼠标点击展开/收起并移出后恢复文件夹，标题不位移。
- AC-02：会话行背景与目录行外侧对齐，标题文字与目录名称起点对齐；无树形竖线，行高32px，时间仍可见。
- AC-03：目录仍可收起/展开，选中会话与管理操作可用。

## UseCase

鼠标移入和离开目录行、用键盘聚焦及切换展开状态，检查图标替换和文字位置；打开已有对话，检查整行背景、紧凑高度与创建时间。

## Tasks

- [x] 图标合并与主题颜色。
- [x] 取消会话缩进，缩减目录和会话行高。
- [x] 验证鼠标点击后移出/移入、键盘聚焦与标题对齐，更新检查记录。

## Issues

原目录同时展示12px箭头与16px文件夹；会话容器有左侧缩进和竖线，占用侧栏阅读宽度。

用户反馈：移除容器缩进后还需保留会话内部padding，保证文字与目录名称对齐；group-focus-within让鼠标点击留下的焦点持续显示箭头，应限制为标题按钮的键盘focus-visible。
