# 设置加载态与滚动条修复

## Spec

状态：两处问题已修复并完成针对性检查，待用户查看；不提交或推送。

### Intent

设置入口点击后立即打开稳定的设置弹窗，按需加载内容时在弹窗内展示加载状态；滚动条与弹窗外框保留间距。

### Constraints

- 保留设置Dialog、通用/模型页和模型内容按需加载，不改变配置协议或认证流程。
- Suspense位于已打开的Dialog内；加载、完成和关闭共用同一弹窗，保留键盘关闭、焦点恢复与聊天草稿。
- 仅调整设置内容滚动区，右侧留12px、上下留20px，不全局改变其他ScrollArea。
- 遵守前端组件、导入与异步规范；只执行覆盖两处问题的检查，不重复整套打包和运行时验证。

### Acceptance Criteria

- AC-01：首次加载模型内容受阻时，设置Dialog已可见，加载提示位于Dialog内部，工作台宽度不变。
- AC-02：加载中可关闭并恢复用户卡片焦点；重新打开并加载完成后仍正常显示设置，聊天草稿保留。
- AC-03：模型页内容可滚动，滚动条与Dialog右侧、顶部和底部存在明确间距，关闭按钮正常工作。

## UseCase

- UC-01：首次打开设置，延迟模型页面模块响应；预期弹窗内显示加载状态，关闭后页面不残留加载侧栏，重新打开后可完成加载。
- UC-02：进入模型页并滚动到后面的Provider，再回到顶部；预期内容正常滚动，轨道不贴外框，关闭恢复入口焦点且草稿不丢失。

## Tasks

- [x] 将弹窗外壳与内容懒加载分离，添加弹窗内加载状态。
- [x] 调整设置滚动区域的局部间距。
- [x] 针对性类型/静态检查、真实浏览器回归及验证记录。

## Issues

- App把整个设置Dialog放在Suspense内，fallback是工作台根flex容器的直接子项；加载时普通Notice被拉成右侧栏。
- 设置ScrollArea紧贴Dialog外框且没有外侧留白，滚动轨道贴近右侧圆角和关闭按钮。
