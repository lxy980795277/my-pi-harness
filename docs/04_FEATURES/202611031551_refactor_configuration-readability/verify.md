# 配置与业务表达治理验证

日期：2026-11-03。工程验证基于0.17.0候选实现，用户后续授权以[0.17.1](../../06_RELEASES/0.17.1.md)收口本地提交；协议23、SQLite9不变。属于M0及既有M1–M5维护，不推送或对外发布。

## 范围与判断

按用户review撤回对象后零散补if的方案，保持ToolRunContext、Agent、主子Run及daemon配置整体。四个仅有机械改写的文件已恢复：services.ts、sessions/runtime.ts、subagents/launch.ts和runs/prepare.ts，与本轮开始时的HEAD一致，新增的无效配置变量、类型导入和RunPreparationInput导出均移除。

用户随后授权覆盖全部package。对五个业务包共203个src TS文件进行候选筛查并人工复核复杂表达，对两个配置包的2份JS实现和3份编译配置及其包清单进行审查。计数含protocol生成的version.ts，只作覆盖记录，不以语法命中数量作为修改目标。

AC-01至AC-04及AC-06通过最终diff、包级覆盖和独立审查核对，AC-05由本表实际检查验证。前一版机械分步装配的检查不作为当前实现的新增证据。
