# 执行与证据方案

范围、用户授权、AC与八项任务由[Spec](spec.md)拥有，本页只说明如何操作和核验。

## 环境与边界

基线从524d59b的0.14.0源码构建macOS arm64未签名应用目录，使用独立userData/profile、动态回环端口及专用Keychain namespace。模型从已有有效配置只读选择，运行前记录实际型号、推理和输入能力；应用登录为合成身份。UI行为由CUA驱动实际窗口。原有5174/4311服务只做T6所需的现有GitHub授权会话，不重启、不复制凭据归属。

控制器放.cache/m1-m5-desktop-acceptance.mjs，接受初始化、启动、脱敏观测/导出、精确故障注入、退出检查和清理命令。它不替UI输入提问/答案、发起Run、编辑工程或生成交付文件；只读API核验不能代替界面操作。故障注入先核对owned PID、临时profile与所记录origin；正常退出使用实际窗口操作，最后确认所属PID消失、端口拒绝连接及namespace清空。

## 输入与oracle

output/m1-m5-acceptance-20261030/fixtures/order-calculator为主要工作区；附件从fixtures/attachments显式上传，相关数据按任务复制至各自独立工作区以避免互相透露答案。audit存放oracle、预先计算的正确结果和校验脚本，不注册为模型工作区、不通过父任务传给子任务。真实公共来源独立核对，不能由验收者补写进Agent输出冒充产品完成。

订单工程基线保留一个已知失败，期望修复整数分折扣的舍入问题，按独立计算验证边界；Agent可以看到普通测试，但不得替换oracle、删测试或隐藏失败。代码调查在原始副本完成，修改任务在另一个副本执行，保证T2不能因T3已修复失去诊断条件。

CSV/PDF/说明故意保留一处可明确解释的结算差异；口径先由原ask_user等待确认，再由计划审核继续。材料由验收者准备，Excel/Word/PDF/PPT交付由产品中的Agent生成。T5给定官方页面，T8固定年度与三城市，缺项允许如实标注但完整成功仍需对应原文支持；网络不可用登记阻塞，不无限换URL。

## 每项记录

- task编号、原始请求、开始/结束时间、实际模型与推理、审批策略、workspace、session/branch/run及相关Task ID。
- UI动作和必要截图、提问/计划/审批来源、工具参数/结果/终态、父子通信与收束；不记录密码、授权头或token。
- 输入及产物hash、下载/重新打开结果、独立数值和结构检查；Office/LibreOffice渲染、PDF页图及视觉问题分开。
- 供应商实际报告的input/output/cache/totalUsage、缺失情况与墙钟时间。没有完整账单或逐模型费用数据时不补算费用。
- 首次失败、原因、受影响范围、修改和复测分别保留，修复后通过不抹掉首败。

## 判定

| 结果             | 含义                                                       |
| ---------------- | ---------------------------------------------------------- |
| Pass             | 实际完成该项所有必要断言并有证据                           |
| Failed-product   | 应用功能、状态、权限、持久化或交互缺陷导致失败             |
| Failed-model     | 传输与工具链正常，但模型误解、算错、遗漏要求或无法完成任务 |
| Blocked-external | 实际所需网络、供应商、授权或外部运行依赖不可用             |
| Not verified     | 未执行，或缺少该结论所需的观察/渲染证据                    |

错误反馈或安全拒绝正确，只能通过对应失败/拒绝用例，不能把原成功任务转为Pass。若多种原因并存，记录主因与全部已观察原因。完成率按8项主任务计算，子断言与横向检查另表，失败/阻塞不能从分母删除。模型质量、应用可靠性和外部可用性分别评价；不以单个模型或有限任务估计全产品统计可靠性。

## 缺陷处理与收尾

已有M1–M5缺陷在原Spec补问题和回归，必要修复先给出可复现证据；产品语义或范围实质变化再补本专题设计。每个修复只重跑受影响链路，保留原平台缺口。所选Office必要渲染、真实GitHub/服务或压缩无法验证时明确留项，不完成原里程碑全部验收。

最终才创建verify.md，归档任务表、具体问题、产物/截图索引及实际检查。原始JSONL、控制器、测试数据和截图留忽略目录，文档仅放脱敏结论和来源；临时模型凭据、owned进程及监听清理后结束。是否提交由用户后续指令决定。
