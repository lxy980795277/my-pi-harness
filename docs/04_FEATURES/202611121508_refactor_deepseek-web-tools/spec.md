# 联网工具与DeepSeek搜索服务

## Spec

### Roadmap Alignment

属于既有M2联网工具与M4插件网关维护，独立于M6本地记忆搜索；不进入M7，不改变终端、沙箱和聊天模型。状态：实现与本机隔离验证完成；真实API和平台未验项见[验证记录](verify.md)。

### Intent

以DeepSeek官方Search/Fetch替换通用网页搜索与正文提取链路。Agent默认使用`web_search`搜索、`web_fetch`读取；保留明确的原始HTTP模式供JSON接口与插件授权网关使用，不增加`http_request`工具。

### Constraints

- `web_fetch`必须明确选择`page`或`raw`，不按后缀推测，不在错误时静默换路。page仅接收URL；raw沿用受控GET/POST、DNS固定、响应边界、取消及精确网关认证。
- 搜索与网页正文使用固定官方端点及独立配置的DeepSeek Key；不借用任意聊天模型凭据，不将Key传给Renderer快照、工具、日志或会话。
- 本地/私有地址与插件网关不得上传到DeepSeek。搜索和正文读取按业务只读；raw POST保持副作用审批与角色权限。
- tools拥有模型工具定义与参数，integrations拥有官方API适配，daemon拥有凭据和生命周期，Web拥有设置和展示；不引入通用多引擎框架。
- 不迁移旧工具参数、不删除真实数据、不修改用户.env；系统凭据存储继续按profile隔离。真实付费API不作为自动验证前提。

### Acceptance Criteria

1. 默认目录含web_search；搜索query/count及官方结果经校验，来源URL保留；空结果正常返回，提供商错误为可行动的安全错误。
2. page返回标题与Markdown；raw支持既有JSON/POST和精确本地插件网关。只读角色允许搜索/page/raw GET，拒绝raw POST。
3. 设置中的“联网搜索”可保存、替换、删除独立Key并只展示配置状态；未配置时工具返回明确说明，不自动回退抓取或借用模型Key。
4. Key更新/删除使旧请求取消，服务关闭等待受管操作退出；超时、取消、非JSON/结构错误、超限、私网目标和重定向均有定向验证。
5. 主/子Run、工具发现、会话结果、折叠行展示与插件Skills使用同一套接口；不存在失效的旧网页路径或重复凭据所有者。
6. 定向回归、类型、静态规则、构建与隔离浏览器/宿主联调通过；真实DeepSeek服务和平台未验项明确记录。

## UseCase

### UC1 配置与搜索

登录后打开设置→联网搜索，填入官方Key保存；状态变为已配置且输入清空。对话调用web_search得到标题、摘要和URL，再以page读取Markdown。未配置、无余额、限流或无正文时显示对应说明，不伪造成功或静默换路。

### UC2 原始接口与插件

Agent以raw GET读取公网JSON；插件Skill以raw GET访问绑定网关，由daemon注入既有授权。page/private目标在发送前拒绝；raw POST按原批准策略执行，只读子任务无法调用。

### UC3 撤销与取消

在受管请求运行时替换或删除Key，旧调用取消，后续调用使用新Key或明确未配置。停止Run、请求超时及关闭daemon均回收网络操作，不泄露凭据。

## Issues

直接API写入的Key原校验只要求存在非空白，允许控制字符直到组装Header才失败；已在协议输入拒绝空白及非可打印ASCII，并以HTTP边界回归证明不落入凭据服务。

## 联网工具重构后的代码治理

范围：既有M2/M4联网链路维护，按用户后续授权检查本轮未提交实现与存量raw工具；不扩展M6本地检索、不提交、不读取或修改真实凭据与数据。

目标：移除有证据的历史分支、重复职责和无消费者代码，保持搜索/page/raw、插件网关、审批和模型输出的职责明确。保留仍有消费者的原始HTTP能力，不以删除文件或增加抽象为目标。

验收：参数与权限行为保持，确认的生命周期/安全错误有回归；新旧调用和当前文档一致，相关测试、类型与静态检查通过，验证结束后记录专项结果。
