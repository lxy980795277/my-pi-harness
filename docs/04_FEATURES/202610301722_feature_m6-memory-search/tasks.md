# M6 实施顺序与完成门槛

本页拆分[Spec](spec.md)的建议范围，机制见[设计](design.md)。当前仅规划；实现与验证任务保持未完成，不把已落盘文档或已有M4工具检索当作M6完成。

## M6.1 显式记忆闭环

- [ ] 确立profile用户/workspace作用域、独立记忆/来源、编辑revision及幂等结果；会话重建保留记忆。
- [ ] 实现认证、有界CRUD及根记忆提案/查询工具，确认关联真实用户动作、内容和scope，不能仅凭full-access直接晋升；子任务没有长期写权限。
- [ ] 设置页可查看、添加、编辑、停用、删除及定位来源，区分记住成功与未确认候选。
- [ ] 接入最小显式选择记忆的请求链路，计入上下文预算并记录实际采用内容。
- [ ] 临时SQLite/JSONL、HTTP及页面证明新会话/重启采用、编辑冲突及忘记生效。

门槛（AC-01–05、07）：从“记住偏好”到新会话真正采用可走通，不是仅CRUD或回答“记住了”。此阶段用显式选择，不宣称自动语义回忆已完成。

## M6.2 持久检索与本地资源

- [ ] 新增持久源查询、文档/分块/FTS5、向量及索引签名，不索引live delta或私有请求。
- [ ] 统一查询/文档分词，确定中文单字、两字词、子串和中英标识符策略并验证。
- [ ] 本地embedding成为真实多消费者服务，前台优先、后台小批、有界取消、显式准备及本地专用查询。
- [ ] 词法与独立语义候选融合、scope过滤、去重、无关空集合及明确降级，不新增向量数据库。
- [ ] 增量幂等、迟到CAS、重建代际/并发补偿、启动对账和向量复用。
- [ ] 验证空缓存离线、准备失败/取消、完整缓存断网重启、模型签名变化、重建保留事实及Worker退出。

门槛（AC-02、08、09、11–13）：持久混合检索独立于工具目录可用，模型不可用仍有词法；不能每次重启重新向量化全部会话。

## M6.3 请求级自动回忆

- [ ] WorkContext/模型Hooks接入有界检索，主子scope由宿主解析，父只转交获准user记忆ID。
- [ ] 相关性门槛、记忆预算类别、去重及每请求替换，不按TopK硬塞固定条数。
- [ ] 协调模型排队/派发与记忆修改删除，失效释放并发名额、有界重建并记录最终实际输入。
- [ ] 上下文详情展示采用条目及来源，支持编辑/忘记，不新增占高状态。
- [ ] 验证workspace、父子/兄弟、reset/分支、暂停回忆、派发前删除及空集合，以实际请求证明生效。

门槛（AC-02–05）：回忆真实影响模型输入且可解释，不绕过M5独立上下文，不以界面标签代替审计。

## M6.4 受控学习与画像

- [ ] 仅手动/自动建议模式；候选在当前根Run内产生，不隐藏增加终态后收费请求。
- [ ] 核验真实来源与明确认可，区分引用/附件、agentMessageId通信、thinking及未确认模型结论。
- [ ] 确认/拒绝、冲突差异、revision校验、重复提议合并和遗忘旧来源抑制，人工更正优先。
- [ ] 有效记忆派生user/workspace画像，来源及编辑共用原条目。
- [ ] 验证旧候选、源变更/归档、删除、重复响应、关闭不复活旧事实；明确普通归档与忘记差异。

门槛（AC-04、06、07、11）：候选可追溯、可拒绝，画像没有第二份事实；网页注入或探索子结果不自动成为记忆。

## M6.5 跨会话搜索与工具整合

- [ ] 统一搜索入口，按会话/记忆、工作区/时间筛选，默认当前可见根消息。
- [ ] 显式历史分支/子任务筛选及准确定位，复用虚拟列表/任务详情，不加载整份历史。
- [ ] 根Run跨会话搜索及精确来源读取；保留search_session_history原语义，子任务不自动获得该权限。
- [ ] 用户引用跨workspace命中时记录精确资料，不扩大模型默认搜索范围。
- [ ] 工具目录保留冻结授权、精确名、命中加载及持久屏障；共享embedding/纯计算后做M4回归。
- [ ] 验证查询切换、分页、注销、源不可用和迟到响应，区分已采用记忆与历史资料。

门槛（AC-02、08–10、14）：用户找到旧讨论并打开准确位置；模型可按明确范围引用证据，搜索不成为越权入口。

## M6.6 联调、质量与交付

- [ ] 按差异运行protocol/storage/runtime/daemon/Web源码、类型及静态检查，补M1–M5回归。
- [ ] 建立至少60条中/英/混合标注查询，含精确标识符、短词、同义零词法重合及无关项，分开校准集和持出集。比较词法/语义/融合的Recall@5及MRR；建议融合Recall@5至少0.85、无关查询自动采用率不高于5%，精确唯一原文定位单列全通过；假向量只证算法，未达标不宣称真实质量通过。
- [ ] 记录设备/数据量/冷暖缓存/并发条件；一万条片段、数百条记忆为初始基准，词法P95不高于300ms、暖混合P95不高于1.5秒作为待实测目标，未达标先定位，不随机截断语料掩盖。
- [ ] 真实临时daemon/Pi/HTTP/SSE/浏览器覆盖记住、采用、纠正、遗忘、学习确认、历史定位、重建与取消交错。
- [ ] 显式执行固定本地模型的质量/资源检查；真实供应商、macOS Electron及Windows分别记录有条件的实际结果。
- [ ] 清理重复状态/无消费者字段/旧路径，更新协议、技术专题、指南及roadmap，实际完成后创建verify。
- [ ] 用户要求提交时走既有流程，保留未验平台/账户和M7范围，不自动清库或发布。

门槛（AC-01–15）：实现、真实模型质量、性能、恢复与权限均有对应证据；文档、界面及假模型通过不能替代必要真实验证。

## 推荐启动点

先做M6.1，建立“显式记住—可管理—新会话采用—忘记生效”的用户闭环，并确定索引及学习依赖的事实、身份和来源。M6.2支撑M6.3/M6.5，M6.4复用已有记忆写入/请求路径；不从全量历史自动抽取或大规模向量化开始。
