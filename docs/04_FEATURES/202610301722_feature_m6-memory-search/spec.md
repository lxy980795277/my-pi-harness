### Intent

用户明确保存的偏好及项目事实可以在新会话、重启后使用，也能纠正、暂停或忘记；Agent能解释本次采用了什么。用户可用关键词或不同表述找到旧讨论，并打开准确的消息或子任务位置。

长期记忆表达当前持续采用的偏好、指令与事实；会话历史保存过去的执行。明确要求记住或纠正时直接保存；开启学习后，Agent可在普通对话中保存稳定偏好。搜索命中、摘要、引文及模型猜测不是自动学习的用户声明。

### 产品方案

- 作用域为user或workspace，由宿主用稳定profile owner和workspaceId解析。默认保存到当前workspace；无workspace时编辑器明确显示user，不按昵称或路径推断，也不暗中扩大范围。
- M6.1从设置页或消息菜单「保存到长期记忆」打开编辑器，明确正文、作用域和「固定采用」后保存。启用的固定条目自动用于该范围的新请求，首版不增加输入框记忆选择器，也不要求每次聊天重新挑选。
- M6.3增加「相关时采用」，适合项目事实和阶段决策；原固定条目保持原使用方式。固定条目不能因排名低而静默丢失，相关条目允许零命中。两者共用独立上下文额度，固定内容超限须说明容量及条目，不能伪称已经全部采用。
- 「使用记忆」与「从对话中学习」默认开启。前者控制自动采用和模型记忆查询；自动学习在两个开关都开启时生效，执行事务再次复核。关闭后仍可人工管理，也可在对话中明确要求保存或修改。
- 根Agent使用save_memory保存用户明确要求记住的内容、update_memory执行明确纠正，直接返回实际写入结果，不再经过待确认建议。learn_memory仅学习稳定偏好、长期指令与事实，排除秘密、临时状态及低信任引文；明确意图由工具说明和模型负责，不新增关键词判断或一次性授权。delete_memory沿统一工具审批，完全访问模式可直接执行。
- 删除提案、确认/拒绝接口、单消息学习动作及其队列元数据。记忆写入展示为普通工具调用，设置页只管理已保存条目。默认保存固定采用；自动学习的偏好/指令默认固定、事实默认相关，支持明确指定。
- 不在回答结束后隐藏增加收费模型请求。自动学习来自正常Agent循环的工具调用；实际来源和工具调用绑定同一根Run，取消及失效来源不能产生迟到写入。
- 画像从当前有效记忆按类别派生，每项可追到原条目；不另存一份自由生成的画像全文。
- 根请求可采用user及当前workspace；子任务仅自动采用当前获准workspace，user条目须由父显式转交精确ID并复核。兄弟历史和父完整回忆包不自动共享，子任务不能写入长期记忆。
- 人类搜索默认当前工作区的可见根消息，可显式扩展工作区、历史分支或子任务。模型跨会话搜索首版仅给根Run，范围由宿主确定；人类筛选不会扩大模型权限。

### Constraints

- 新增独立`packages/memory`领域包，拥有记忆规则、直接写入、采用选择及画像，通过窄端口访问存储和检索；SQL仍归storage，模型工具定义归tools，运行时只做绑定/上下文/调度，推理Worker继续归daemon/search。详细分工及代码依据见[设计](design.md)。
- 记忆、设置及幂等结果是同一profile SQLite中的独立事实；不进入会话重建删除清单，不以会话投影表为级联外键，不新增memory JSONL或第二套消息系统。FTS、向量和实际采用展示是可重建派生数据。
- HTTP、模型参数、Worker和持久数据在原入口校验；宿主同进程通过准确类型传递。模型/客户端不能自报owner或扩大scope。save/learn/update不额外请求工具审批，仍受根Run、作用域、来源及revision校验约束；删除沿通用审批。
- M6.1即拆开请求草稿与最终审计：准备/必要压缩、获取模型名额、复核当前记忆及授权、提交最终输入、交给Provider。失效先释放名额再重组，不能持有名额调用摘要模型。保证截至宿主Provider交接点，不能撤回已交出的请求。
- 队列不冻结长期记忆正文；实际请求读取当前有效事实。follow-up/steer按本次实际已消费输入召回，不永久使用Run首条问题。通信不因为role=user就成为真实用户声明。
- 记忆作为本次投影资料，不写入原始user消息、共享basePrompt或摘要副本。实际采用正文进入既有请求快照；复用prompt中的单个结构化记忆块，不再写第二份正文日志，范围校验与界面派生见设计。
- 停用、忘记、关闭采用和归档会话语义分开。忘记撤去后续查询/采用与派生索引，不重写既有请求、回答和日志；已保存的独立记忆不因来源会话归档而自动消失。
- 历史索引仅来自有界的持久正文查询，排除live delta、system、thinking、私有codec、凭据、原始工具大结果及默认未选的附件。普通根搜索不自动带回当前分支编辑/reset已舍弃的内容。
- 索引与普通查询不触发权重下载；显式准备固定模型后才启用本地语义能力。离线/不可用时词法继续工作，取消不能被吞成普通降级。当前没有累计token额度或固定循环次数限制，本轮不恢复它们。
- 本轮按上述方案完成开发与本机验收，限制、实际性能及未验平台由验证记录说明，不以源码或文档存在代替验证。

### Acceptance Criteria

- AC-01：保存、纠正、停用和忘记由真实宿主完成，幂等和revision冲突明确；新会话及重启采用有效事实，会话投影重建不丢记忆。
- AC-02：profile/user/workspace及无workspace隔离，过滤先于TopK、分页、向量排序和计数；未授权正文、片段及来源不泄露。
- AC-03：固定及相关采用计入总上下文，不与system重复计费；关闭采用、超限、低相关及省略原因可见，不声称固定条目全部采用却静默裁剪。
- AC-04：排队期间新增、修改、停用或忘记会触发派发前复核；不发送旧版，不持有模型名额再压缩，连续变更有界失败，流真正结算后释放名额。
- AC-05：实际采用ID/revision/scope/来源及正文可从最终请求还原，日志正文不额外重复；Unicode、转义、非法块范围及codec重建有真实拒绝用例，界面不以当前记忆回填历史。
- AC-06：子任务仅拥有获准workspace及显式转交user ID，父/兄弟历史不默认下放；父关闭采用策略及后续遗忘对下一子请求生效。
- AC-07：明确保存/纠正直接生效，稳定偏好在默认开启的学习设置下可直接保存。关闭学习阻止learn_memory但保留明确保存；关闭使用也阻止自动学习。CAS、真实来源/工具绑定、幂等和取消仍生效，删除遵守统一审批。
- AC-08：引用、网页、附件、摘要、thinking、通信及未认可Agent结论不自动晋升。画像从有效条目派生；默认没有隐藏终态后推理。
- AC-09：归档/分支/reset及时调整历史可见性和写入来源资格；已保存记忆保留独立事实与来源状态。遗忘指纹不保留被忘记正文，旧工具调用/向量/重建不能复活它。
- AC-10：中英混排、两字词、明确单字、标识符、同义零词法命中、无关查询和稳定去重排序分别验证；语义候选独立产生，不只重排词法命中。
- AC-11：增量索引、取消、重建代际及并发补偿正确；重启复用有效向量，坏缓存不改变记忆事实；后台积压不阻塞启动或普通发送。
- AC-12：模型准备与普通查询分开，冷/暖/离线状态可见；前台优先、后台有界，取消后的实际计算仍被追踪，关闭等待Worker退出。
- AC-13：命中可打开精确根消息、历史分支或子任务目标页；阅读不修改执行分支、不要求停止活动Run，不全量加载转录或查找未挂载DOM。
- AC-14：人类跨范围引用只授予所选来源/片段，输入接受时复核并保留精确引用；后续工具读取不因此获得全部工作区搜索权限。注销/切换清理客户端私有结果和迟到响应。
- AC-15：M1–M5回归、临时存储/API/浏览器、真实本地检索质量和性能、macOS桌面分别记录；必要证据完成后才创建功能verify，其他平台和真实外部账号保持原状态。

## UseCase

### UC-01 保存与新会话采用（AC-01–03、05）

设置或消息菜单保存「回答使用简洁中文」，明确选择user和固定采用。新建会话及重启后实际请求包含该条；在A工作区保存的项目事实不会出现在B或无工作区。固定内容超限时看到明确处理入口，不能仅得到「记住了」。

### UC-02 纠正、遗忘与请求排队（AC-01、04、05、09）

用可控模型名额阻塞请求，期间修改或忘记条目。放行后Provider收到新版或不再含该条，最终请求及采用面板一致；已发出的旧请求按原快照解释。并发编辑冲突、确认重试和旧异步回写均不能覆盖新事实。

### UC-03 主子任务与当前输入（AC-02、04、06）

根Run连续接收新输入，按实际消费内容替换相关回忆。子任务仅采用workspace固定项；显式转交某一user条目后才可读取它，兄弟不可自动获取。暂停采用或遗忘后，尚未交接Provider的请求重新准备。

### UC-04 对话直接保存与自动学习（AC-07、08）

说「记住，我喜欢先看简洁的中文结论」，save_memory直接保存，下个请求可采用。默认开启学习时，普通对话里的稳定偏好可经learn_memory保存，不产生待审阅项。关闭学习后该调用失败，明确要求保存/纠正仍可执行；关闭使用同时阻止自动学习。引文不自动变为用户偏好，子任务不能写入；普通审批模式删除须批准，完全访问模式直接执行。

### UC-05 历史搜索与只读定位（AC-02、10、13、14）

搜索「上次讨论的子任务额度」、两字词或精确标识符，找到原话并打开准确位置。活动Run继续执行，历史阅读不写branch.selected。显式选择旧分支或子任务后显示其来源；结果陈旧时返回来源已变更/不可用，不能跳到相似文本冒充命中。

### UC-06 索引与本地资源（AC-09–12）

空缓存离线时仍可词法搜索且不下载；显式准备、取消、断网重启及后台索引时前台查询有界。重建途中删除记忆、归档会话或切换分支，迟到向量不复活旧内容；模型签名变化只使派生向量失效。

### UC-07 关闭、来源与采用记录（AC-05、09、14、15）

忘记后管理页、画像和后续采用不再出现该条，已提交请求仍能解释当时内容；来源归档不默默删除独立记忆。切换目标、注销和退出分别清理页面请求、查询、索引及Worker，并保持原后台Run的拥有关系。
