# 工作区选择与自定义图标

## Spec

状态：实现与macOS本机验证完成，待用户体验验收；浏览器新增目录按用户决定后续补齐。[验证记录](verify.md)列出证据与平台范围。未提交或推送。

本页保留目录/图标交付及紧凑尺寸基线；后续焦点样式分离、wire5工具快照和本地提交由[M2最终收尾](../202610151555_refactor_m2-finalization/spec.md)接续，当前协议以API文档为准。

### Roadmap Alignment

属于[roadmap的M2工作区管理](../../00_OVERVIEW/roadmap.md)，在既有M2基础上改善已实现交互，不新增M3上下文能力。Windows Shell仍按原决定暂缓，与本次目录UI无关。

### Intent

添加工作区使用标题、图标与名称输入、文件夹选择区表达操作，移除重复说明和手工路径输入。支持点击选择本机目录以及Electron拖入目录，图标选择保存后在工作区入口一致展示。

### Constraints

- 名称输入前提供固定Lucide图标选择面板，仅图标，不加入emoji或颜色选择；默认folder，旧工作区迁移后保持默认图标。
- 弹窗常规状态整体高度约320px，名称输入36px、目录选择区112px；图标面板宽256px，图标点击区域至少32px。长路径单行省略并保留完整悬停提示，错误提示按内容自然增高，不硬裁剪。
- 图标为protocol声明的固定ID，服务端校验；Workspace响应新增必填icon，wire版本升4并更新所有消费者。追加0004迁移，不改历史迁移、事件或工具codec，更新字段遵守revision。
- 目录区域点击调用已有系统目录选择器；选择后展示不可编辑路径并可更换。保留取消、pending、错误、键盘操作及关闭后的异步取消/过期结果保护。
- Electron拖放仅接受一个真实本机目录，preload用webUtils.getPathForFile获取真实路径，main验证所属主frame、参数、realpath与目录类型，注册仍经过daemon根策略。拒绝合成File、普通文件、多项目与未知拖放输入，不读取目录内容或上传副本。
- 用户已明确选择本轮先完整支持Electron，浏览器新增目录后续补齐。浏览器移除手工路径输入，选择区提示在桌面添加，仍可使用和编辑已有工作区；不得伪造路径、遍历磁盘猜目录或假装上传成功。
- sidebar中默认folder继续按展开状态显示FolderOpen/Closed；自定义图标使用同一尺寸/现有色彩，hover与键盘focus-visible仍切换为展开箭头。
- 冗余说明只删除标题/控件已能表达的句子，保留权限、不可逆后果、必要认证步骤和错误恢复信息。设计规则同步到设计语言。
- 遵守前端TSX/Hook分工、shadcn组件、无三目/void/Promise链；不放宽桌面来源与文件操作限制。

### Acceptance Criteria

- AC-01：添加弹窗不显示指定重复说明，不存在手工绝对路径输入；标题、名称、选择区、取消/保存足够完成操作。
- AC-02：点击选择区打开目录选择器，取消不清空已选目录，选择后显示实际路径，重复选择/保存不混淆状态；目录可拖入，文件/多目录/合成File明确拒绝。
- AC-03：图标面板展示固定Lucide选项，键盘可操作；创建或编辑后侧栏与工作区选择入口一致显示，刷新/重启仍保留；旧库升级默认folder，非法图标拒绝。
- AC-04：默认folder的展开/收起与hover箭头不回归；浅深主题和较窄窗口布局、焦点及错误状态可用。
- AC-05：最终按用户确认的浏览器范围实际验收并记录，不能把模拟bridge当成真实系统目录选择/拖放证据。

## UseCase

- UC-01 添加：打开弹窗、选择图标、选择目录、填写或省略名称、保存，侧栏与新对话工作区选择一致，刷新保留。
- UC-02 更换目录：已有选择后再次点击、取消保留原值；新选择覆盖旧值，关闭弹窗后晚到响应不能改变下一次表单。
- UC-03 拖入：拖入单个真实目录得到高亮与路径回填；普通文件、多个目录、未知或合成File不成为有效工作区。
- UC-04 图标编辑：打开已有工作区编辑，只调整名称/图标而不能换根目录；保存后版本递增，过期revision拒绝。
- UC-05 兼容：旧库迁移后原ID、路径、会话关联与默认图标保留；目录注册安全策略保持不变。

## Issues

已解决：添加弹窗重复解释工作区语义、要求手工路径输入且Workspace未持久化图标。目录选择区通过有限桌面桥接入实际路径，固定图标经迁移与API保存。模型配置删除重复的操作说明，保留凭据安全信息；模型管理移除重复的功能说明，并同步处理无描述Dialog的可访问属性。

范围决定：浏览器目录句柄与daemon宿主路径不能直接互换，用户明确将浏览器新增目录留待后续；保留已有工作区使用和名称/图标编辑。
