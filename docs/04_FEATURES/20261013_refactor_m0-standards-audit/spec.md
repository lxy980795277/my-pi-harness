# M0规范与架构审计

## Spec

状态：本机范围完成，结果见 [verify](verify.md)。本次覆盖依赖审核、Magic Book范式对照、详细约束、M0架构/代码/ESLint扫描及修正，不包含commit、push或M1业务开发。

### Intent

将M0从可运行工程底座完善为有详细规范和可执行检查的开发起点。依赖采用较新且稳定的受支持版本，不机械追随latest；React/Zustand规范按Magic Book保留通用细则，其他规范达到相同详细程度。

### Constraints

- 保留已确认的Electron + 独立Node、共享Web、Pi后续接入架构，不复制标杆业务实现。
- Magic Book的React/Zustand通用规范可直接沿用；Next.js、NestJS、Prisma/MySQL、Tiptap及旧产品业务规则按本项目实际职责改造并注明取舍。
- 版本依据官方发布策略、npm版本元数据、依赖peer与真实运行验证选择，排除预发布；平台与工具兼容优先。
- 文档规定具体所有者、写法、异常处理、示例和审查方法；能够机械检查的重点规则落实到实际gate并验证拒绝无效输入。
- 修正M0的真实架构/生命周期/安全缺陷，避免新增空模块、假Zustand状态或未实现的Agent能力。
- 不改变用户现有授权规则，不把确认节点变成重复审批；不宣称未执行的Windows或CI检查成功。

## Issues

提交前发现未显式提供的peer自动解析到Vite8与ESLint10.12，catalog声明不足以约束这类依赖。已在测试程序与共享配置显式提供catalog peer，并核对lock及消费者真实解析路径；重跑受影响检查的结果记入verify。

| 问题与复现                                            | 根因                                               | 修正与预防                                                                             |
| ----------------------------------------------------- | -------------------------------------------------- | -------------------------------------------------------------------------------------- |
| ESLint9已EOL，部分工具使用极新版本或互斥peer          | 单包追版本未联合检查支持窗口                       | 采用支持线与兼容组；版本记录给出每项依据，strict peer保持开启                          |
| 手写控件不符合FC/独立目录规范，传输客户端分散         | 文档只有简略约束，缺少可执行规则                   | 独立组件与HTTP/SSE客户端，补React/Zustand细则及真正拒绝fixture                         |
| Electron启动未完成时退出或重复before-quit可能绕过清理 | daemon句柄尚未赋值或退出重入                       | 启动取消信号、共享关闭Promise、真实子进程取消回归                                      |
| HTTP重定向、新frame导航及session权限缺默认拒绝        | 只处理部分导航事件和权限请求                       | 导航/重定向来源检查、check/request双拒绝，非法窗口/frame/参数回归                      |
| SSE HEAD请求挂起、慢客户端心跳累积                    | Fastify自动HEAD与write背压未处理                   | 禁止SSE HEAD、背压跳过heartbeat，真实连接测试                                          |
| 发送半个HTTP headers后daemon关闭挂起                  | 不完整请求仍占用HTTP连接                           | preClose结束SSE，Fastify主动关闭剩余连接；真实TCP回归保留SSE正常EOF                    |
| 配置PID超过操作系统有效范围                           | safe integer不等于有效PID                          | 入口限制int32正范围，非法范围回归                                                      |
| 开发进程树退出未等待，Windows环境PATH可能重复         | 单次发信号、taskkill未观察结果、大小写环境键未归一 | 有界等待与强制回收、幂等stop、单一PATH；真实进程树回归                                 |
| 全依赖audit报告sprintf-js中危                         | electron-builder构建链的传递依赖，公告无修复版本   | 保留已验证builder，不强制替换不兼容依赖或隐藏公告；生产audit零报告，发布前继续检查上游 |

Windows本机执行、正式签名、公证与安装器不属于本轮已获得证据；Windows开发工具在leader提前退出后的孤儿树限制由验证记录明确。Agent、工具、SQLite与Computer Use仍由后续里程碑拥有。
