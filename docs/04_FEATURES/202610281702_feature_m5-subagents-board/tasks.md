# M5 实施任务与完成门槛

本页拆分[M5 Spec](spec.md)的已确定范围；机制见[执行与数据设计](execution.md)。M5.1–M5.5工程实现及macOS自动化验证已完成，实际结果见[验证](verify.md)；用户体验、真实供应商、Electron和Windows实机验收保留未完成。每阶段提供可走通的用户链路，不以工具占位、界面样例或测试替身代替实际实现。

## 模块归属

| 模块                                            | 实施职责                                                                          |
| ----------------------------------------------- | --------------------------------------------------------------------------------- |
| packages/protocol/src/sessions                  | Task/命令/摘要DTO、Run的taskId、任务作用域、事件与分页校验；不含Pi对象或服务实现  |
| packages/agent-runtime/src/agents               | 角色解析、任务接受/调度、关系、预算、通信与结构化结算；按实际职责建文件           |
| packages/agent-runtime/src/runs                 | 主子共用的Pi准备、模型lease、工具循环、取消和终态；不另写子Agent循环              |
| packages/agent-runtime/src/context、work、tools | 任务上下文与压缩、独立交互/队列、委派工具、权限收窄、统一工具审计与写入拥有者检查 |
| packages/storage/src/sessions、sqlite、profile  | Task/通信/WorkState投影、关联校验、Run作用域、日志重建、全树中断与有界查询        |
| apps/daemon/src/agents及application             | 任务API、角色/限制配置、服务装配、SSE与关闭；不创建第二份运行事实                 |
| apps/web/src/features/tasks                     | 看板、树、详情、任务命令及查询Hook；只有选择/筛选/展开等展示状态进入Zustand       |
| apps/web/src/features/sessions、work、tools     | 固定header入口、主聊天过滤、来源标记与原人工交互复用                              |

- [x] 2.7 / AC-03–06：临时真实运行验证并发争用、嵌套通信、跨树拒绝、双写竞争、额度超限和旧配置行为。

阶段门槛：并行任务在受限资源下可终结，通信和续作不重复，任何嵌套不能扩大权限、复制额度或写入拥有权。
