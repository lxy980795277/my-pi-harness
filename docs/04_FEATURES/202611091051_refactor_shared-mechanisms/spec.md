# 共享规则与状态归属治理

## Spec

### Roadmap Alignment

属于M0与既有M1–M5维护。M6继续仅规划；既有真实账号、Office视觉、Windows与正式安装验收缺口保持，不新增产品能力。

### Intent

按审计确认的实际重复和职责漂移收敛共享规则：让授权判断、目录状态、队列私有数据及网络安全原语各有唯一拥有者，消除重复扫描与前端生命周期实现，保留不同领域的真实边界。

### Constraints

- 用户于2026-11-09确认实施审计方案，后续明确授权按0.19.1本地提交；不以最小改动、减少文件数或建立通用抽象为目标，不推送或读取真实凭据与会话。
- 独立高级账户与插件授权分别管理身份和生命周期；插件可用性由精确pluginOwner引用判断，官方endpoint和身份epoch检查保持。
- MCP只读授权统一当前身份、配置、定义与控制代次判断；调用时的精确参数hash校验继续执行。启动信任、只读授权与逐次审批不合并。
- 目录发现状态由现有CatalogCache管理；物理连接回收诊断独立保留。凭据批量删除尝试全部引用后报告失败，不回滚已提交配置或引入新的持久清理队列。
- 队列私有数据唯一定义于protocol/internal，持久化与回放入口继续校验；同进程已校验值通过明确类型传递。公开protocol及internal继续不依赖Node。
- tools拥有Skill发现、排序、内容与冻结验证，daemon拥有启用与有效覆盖规则；一次操作使用同一发现快照，不新增跨请求缓存。
- sandbox只复用DNS校验、取消与连接地址固定机制；Web网关、重定向、请求体及远端OAuth/MCP访问策略继续由各自领域拥有。
- 附件只共享声明性格式、MIME和大小事实；宿主内容验证保持。模型OAuth归models，应用登录归auth；下载Hook只管理Blob URL和临时链接生命周期。
- 保留运行时/存储/协议各自会话职责、子任务内存/历史投影、附件/产物存储、RunHooks及不同OAuth拥有者。不为少量hash计算另建package或将Node crypto放入protocol。

### Acceptance Criteria

- AC-1：独立账户关联的手动MCP不要求安装插件；有pluginOwner的MCP仍按精确贡献引用及身份/epoch拒绝失效授权。
- AC-2：MCP目录展示、候选筛选、冻结和实际调用使用一致的当前授权规则；身份撤销后旧授权不得被展示为可用。
- AC-3：本地与远端MCP更新/删除后，所有不再使用的秘密引用均被尝试清理，失败使用安全诊断；显式及后台发现状态一致，迟到结果不能发布。
- AC-4：队列私有数据schema/type唯一定义，存储返回已校验类型；运行时不再重复同一校验，持久数据非法用例仍被拒绝。
- AC-5：Skill详情和冻结每次只发现一次，有效启用/覆盖规则由daemon唯一计算，冻结仍验证源内容未变。
- AC-6：受控网络共享DNS与地址固定原语，所有地址公网校验、取消和连接固定保持，各领域访问策略不被放宽。
- AC-7：模型OAuth、附件声明与下载资源生命周期各有明确拥有者；取消、失败和卸载清理保持，不影响应用登录。
- AC-8：移除确证未用的RuntimeStore恢复端口；相关静态、类型、行为、构建及隔离部署检查通过，验证后记录实际证据及未验证项。

## UseCase

- UC-1：用户使用独立高级账户连接官方手动MCP；未安装插件仍可按本身配置、信任和审批执行，插件MCP禁用或身份变更后仍拒绝。
- UC-2：用户撤销身份后重新信任MCP，旧只读授权不再出现在可选目录；新的授权按精确参数执行。
- UC-3：MCP保存配置后某一秘密删除失败，其他旧引用仍执行清理；显式发现失败、重试成功和后台取消显示准确目录状态。
- UC-4：输入排队、编辑、启动及重启回放使用同一私有契约；未知字段、非法绑定或超限数据在持久入口拒绝。
- UC-5：重名Skill按启用状态选择有效来源；同一次详情/冻结操作的元数据和正文来自同一发现快照，源变化仍使冻结失败。
- UC-6：DNS返回混合公网/私网地址或用户取消请求时，Web及远端访问均拒绝或中断；真实连接只能使用已验证地址。
- UC-7：模型授权完成只刷新模型状态；附件选择/上传/宿主接收使用一致格式和上限；下载成功、失败、重复操作和页面卸载都释放资源。

## Issues

实施复审补齐远端OAuth客户端秘密替换/删除的批量清理，以及本地只读绑定缺少冻结控制revision时的拒绝。浏览器发现旧日志错误fixture缺少ApiError的code，已修正fixture并保留严格解析。下载清理使用明确目标身份，避免把回调引用变化当作目标切换。当前无阻塞，实际检查、已解决的验证问题和外部验收范围见[验证记录](verify.md)。
