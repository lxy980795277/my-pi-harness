## 实现与观察

成功输入轮次的思考、中间说明和工具合为默认关闭的“已处理＋耗时”行，最终正文及原整答操作/统计在外。耗时沿用用户输入至结束的时间范围，不是单独的思考时间。纯文本无过程不产生摘要；活动、等待批准、提问/计划审核、未知、停止及失败结果保持原可见性。同Run排队输入、继承分支和非正常最终消息由纯投影回归覆盖。

生成期间思考与正文已是独立稳定行，原MessageView不复制或改写。关闭过程会卸载子内容；过程和工具开合由内存Store分别保存，跨虚拟卸载及切换会话保留，刷新默认关闭，注销统一清理。实际浏览器验证键盘Enter/Space、嵌套工具开合、重新展开不增加模型请求，以及长历史仍仅挂载有限虚拟条目。

浏览器回归曾复现展开后摘要移动1386px、自动收起时阅读段落移动588px，以及最后思考改变正文行内部高度引起32px位移。最终实现通过跟随/阅读/显式过程操作三种模式协调库锚定，并从生成阶段拆分思考与正文。最终回归中，展开摘要及自动收起前后正文段落位置的端点差均不超过2px；该采样不等于所有呈现帧或其他缩放比例均无位移。
