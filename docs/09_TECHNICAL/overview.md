# 技术记录

[决策记录](decisions.md) 保存非显然选择的理由、条件和代价；当前技术事实以架构为准。[问题记录](lessons.md) 保存实际出现的根因、复现与预防规则。

技术调研优先使用官方文档和维护者材料，区分已确认事实、推断和待验证项。必要约束同步到对应规范，避免把历史问题记录作为当前实现的唯一入口。

[AI Coding范式映射](development-paradigm.md) 逐项对应Magic Book的AGENTS、docs00至10及本仓库取舍；[依赖版本审计](dependency-versions.md) 记录当前版本选择、官方支持证据和后续维护策略，不复制历史业务方案。

## 记录方式

决策记录写日期、状态、决定、原因和改变决定前需解决的条件；涉及迁移或发布时写明影响。不是每个普通代码选择都需要ADR，稳定事实更新架构，不在理由中重复完整配置。

问题记录写实际现象、最小复现、根因、修复与可执行预防；长期规则更新05_CONSTRAINTS。未复现的怀疑标为调查，不编写虚假根因或完成结论。
