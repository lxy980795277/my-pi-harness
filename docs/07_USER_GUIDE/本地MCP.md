# 使用本地MCP工具

本地MCP把一个已安装的stdio程序提供的工具加入对话。当前在macOS运行，工具属于指定工作区；远端HTTP/SSE与MCP OAuth见[远程MCP与目录管理](MCP扩展.md)。程序启动本身可能执行操作，因此启动授权和每次工具审批分别确认。

## 添加与启动授权

1. 点击左下角用户信息卡片，选择“设置”→“MCP”，展开“高级配置”，点击“添加本地 MCP”。
2. 填写名称、所属工作区、启动程序的绝对路径、参数与普通环境变量。程序需要预先安装，应用不会自动运行安装命令。参数逐项提供，不把整段Shell命令填入程序路径。
3. 需要API Key等秘密时先声明秘密槽位及目标环境变量名，保存后通过“秘密”单独填写。不要把秘密放在参数或普通环境变量中；秘密保存到系统凭据库，页面只显示是否配置。
4. 选择“受监管隔离”或“完全访问权限”，点击“启动授权”。核对程序、参数、工作根、环境变量名与网络范围后确认。预览和确认不启动程序。
5. 点击“发现工具”或“测试连接”。这两个明确动作会启动本机程序并读取目录，结束后关闭连接；看到“未连接”不表示目录发现失败。

受监管隔离默认限制工作区与临时目录访问，不开放网络。程序或其依赖不在允许读取范围、需要网络时，启动可能失败；应用不会自动升级权限。完全访问权限以当前用户权限运行，扩大文件与网络访问范围，需另行明确授权。两种范围不能相互继承。

## 在对话中选择

先选中对应工作区和批准方式，再从输入框加号中的“MCP工具”选择已发现、可用的工具。请求批准或帮我批准使用“受监管隔离”目录，完全访问权限使用对应目录；尚未发现时先回设置完成该范围的授权与发现。内部只读审批模式只允许你明确确认过的工具定义及精确参数只读授权。

首次发送、后续输入、队列编辑和历史消息编辑均携带这次选择。运行中的显式选择保持冻结；Agent可检索接受时冻结的已授权目录，并显式加载需要的完整工具定义，下一次模型请求才可调用。新发现的定义不会无声替换旧Run。修改程序、参数、工作区或秘密会使原授权失效，需要重新授权与发现；旧队列不会因重新授权而自动切换到新工具。

工具沿用对话中的单行展示，点击可展开参数与结果。启动授权不会略过请求批准或独立AI复核；具体调用仍按当前策略处理。

## 停用与结果未知

“停用”或“撤销授权”会封禁旧授权并回收连接，重新使用需要再次启动授权；“删除”移除配置与系统秘密引用，已记录的对话日志保留。活动调用期间普通编辑、删除和秘密轮换会提示忙碌，显式停用、撤销或删除凭据仍会立即撤销旧授权。

出现“结果未知”表示操作可能已生效，不能当成普通失败后直接重试。当前Run会停止，待执行输入保留；先核对目标系统的实际状态，再用新的明确输入决定下一步。应用重启不会重新启动旧工具或沿用旧审批。

退出当前浏览器登录保留已接受运行及profile级启动授权。需要停止外部程序的访问时，使用Server的停用或撤销入口。详细范围见[MCP目录与本地协议](../03_API/local-mcp.md)，数据位置见[会话存储设计](../09_TECHNICAL/会话存储与恢复设计.md)。
