# 服务插件授权

安装GitHub、Google等插件后，点击「授权」即可打开独立授权窗口。窗口会自动前往供应商同意页，完成后插件详情显示账号，并提供「断开授权」。页面无需添加、选择账户或填写Client ID/Secret；关闭窗口会结束本次页面等待，重新点击授权可以重新发起。

应用维护者需事先配置专用OAuth客户端，与应用登录分开。环境变量和回调地址见[插件协议](../03_API/plugin-connections.md#客户端与凭据)及根`.env.example`；GitHub插件不会回退使用应用登录配置。当前本机仅配置应用登录时，插件会明确显示客户端未配置，需要维护者补齐服务配置。

插件授权供Skills的只读服务网关使用，也供GitHub/Google所含MCP Apps使用。Apps默认关闭，分别打开相应应用的开关即可开启该固定服务；点击应用可进入详情查看状态和工具。其他供应商的App可能需要独立MCP授权。插件已授权不代表所有MCP工具已获准或供应商已开通相应服务，具体工具仍遵守对话审批策略。

Google覆盖Drive、Docs、Sheets、Slides和Calendar，需要在供应商项目启用对应API及权限。实际供应商审核、MCP准入、团队或组织权限由服务端决定；本机授权状态不能代替这些条件。

插件凭据只保存在本机profile的专属0600文件，不回显或写入对话。断开撤销该插件的凭据与连接，应用登录保留；卸载清理所属授权与资源，手动账户和其他插件保留。桌面版通过系统浏览器完成同样流程，使用一次性启动链接；该链接无需浏览器预先登录本应用。

「外部服务连接」保留高级手动账户与Token管理，与插件默认流程无关。其配置、取消及系统凭据规则见[高级账户协议](../03_API/connections.md)。本轮自动验证使用独立本机服务、明确假客户端和合成账号；真实供应商账号及系统浏览器仍需单独验收。
