# 使用模型与会话

M1提供文字对话、配置与认证、停止、持久队列和历史分支。M2新增工作区与有审批的工具执行，操作见[工作区与工具](workspace-execution.md)。M3的附件、上下文、计划与检查点见[对应指南](context-interaction.md)；MCP、子Agent、记忆和Computer Use仍在后续里程碑。

## 进入工作台

先完成[GitHub应用登录](application-login.md)。Electron自动建立本机信任，浏览器先配对再登录；配对本身不授予会话、模型或工作区的访问权限。

## 配置模型

点击侧栏底部用户信息卡片，选择上方菜单中的「设置」，再进入「模型」。内置厂商仅保留OpenAI（原Codex legacy目录）、Anthropic、Google、DeepSeek、MiniMax和Kimi（Kimi Coding）；其他服务可通过自定义Provider接入。内置厂商已经列出，直接在对应卡片点击「配置」完成认证；开关控制其是否参与后续模型选择，点击「模型」查看Pi提供的只读目录。

自定义服务使用「添加 Provider」，填写名称、具体协议和Base URL，选择是否需要API Key。可以先保存Provider，再在其「模型」弹窗添加模型ID、上下文和输出限制、推理能力。远端要求HTTPS；本机显式回环服务可以用HTTP。OpenAI兼容服务通常填写包含 `/v1` 的地址；Anthropic填写根地址，SDK会追加 `/v1/messages`。无需Key的本机服务关闭Key要求，实际请求不携带占位认证。

密钥在Provider配置弹窗内填写和保存，提交或关闭后清空输入；已有凭据只展示脱敏状态。密钥与OAuth凭据留在profile专属系统凭据库，不保存在会话数据库。若系统凭据库不可用，服务明确报错，不改用明文文件。

在「模型」弹窗对具体模型发起连接测试，它会产生一次真实短模型请求。保存成功只表示配置已接受，测试结果单独显示。使用真实供应商时该测试可能计费；未通过测试的自定义配置仍可编辑。

支持OAuth的内置Provider在配置弹窗内提供登录入口。按其中的地址、设备码或输入挑战操作；桌面通过系统浏览器打开所属授权流程地址。关闭Provider配置或设置弹窗会取消其未完成授权；成功后关闭配置并刷新厂商状态。已有认证可以退出后切换方式。

在模型设置顶部选择默认模型与思考等级，后续新会话使用这组设置。默认配置失效时重新选择；当前会话和正在运行的请求保持其原有选择。关闭设置回到原会话，草稿与已保存历史保留。

进入工作台前需完成[GitHub应用登录](application-login.md)，它与GitHub Copilot模型认证分别管理；应用登录不会授予模型调用权限。

## 对话、停止与输入队列

点击左侧“新对话”，直接在居中输入框输入文字，首次发送才创建会话。输入框下方可选择工作区、审批策略与对话模型；默认从已保存的模型偏好开始，也可明确选择其他模型。时间线呈现回复和推理内容，中心区域滚动，输入栏保持在底部。会话顶部全宽展示标题与日志下载，连接中/重连状态在右侧下载按钮左边单行显示；后续Run的模型/推理级别在输入框中设置，进行中的Run保持已接受参数。

Enter发送，Shift+Enter换行；Ctrl/Cmd+Enter也可发送。中文输入法确认候选词时不会发送，确认完成后再按Enter即可。未选择可用模型、草稿为空或正在提交时，快捷键与发送按钮保持相同限制。

请求接受后、模型尚未返回内容时显示“正在等待响应…”，可以继续等待或点击停止。刷新后重新选择会话能恢复运行状态；事件连接中断会明确提示，断线本身不会停止后台执行。若进入页面提示服务版本不兼容，重启开发服务后点击重新连接，已保存的回复无需重发。

回复进行中提交的新输入默认排队，在当前回复后继续。待执行面板可查看、修改和删除尚未消费的输入。停止会取消运行并保留未消费队列；恢复需要展开面板并明确继续。发送普通新消息不会偷偷恢复旧暂停队列。

恢复队列沿用接受时记录的Provider/model；如已经切到编辑后的新分支，先切回原分支。服务失败或异常退出后不会自动重发请求，重新打开会话可以查看已保存部分及interrupted状态，再决定是否继续。

输入框下方固定显示“上下文占比 | 总对话次数”，空会话为0次，次数只统计当前分支已接受的用户输入，工具轮和待发送队列不增加。上下文尚未记录时显示“—”，点击上下文文字可打开详细工作状态。

## 阅读与消息操作

助手回复和展开后的思考内容支持Markdown标题、列表、引用、表格与代码；代码块可以复制，宽表格和长代码在自己的区域内横向滚动。用户输入保留原始文字，工具参数、文件差异和执行结果单独展开查看。生成中仍可阅读，向上滚动会暂停自动跟随，点击“回到最新消息”恢复。

普通网页链接在新页面或系统浏览器中打开；模型给出的图片链接不会自动下载，上传附件仍可使用原有预览。

工具以“图标 名称 · 内容”单行显示，执行/复核中以行首loading替换工具图标；悬停或键盘聚焦时显示展开箭头，点击后查看参数、差异和结果。需要批准时相关内容与操作直接可见，失败等异常保留状态提示。思考内容也可按需展开。

工具调用前后的正文属于同一次回答，末尾统一提供“复制回答”，按原顺序复制该次回答全部助手正文，保留Markdown原文，不包含思考或工具结果。用户消息和代码块分别保留自己的复制操作。完整回答下方显示模型token用量、总耗时及回答时间；悬停可查看精确用量细分与完整日期。用量累计本次输入的主对话模型轮（包含工具轮），不包含独立审批复核与上下文压缩请求；耗时包含本次输入开始后的工具执行和等待。同一Run内的后续输入分别统计。供应商未上报或历史没有记录时明确标注，部分步骤缺失时显示“部分用量”。

## 编辑、历史与归档

提问下方的复制和编辑按钮默认隐藏并保留位置，悬停消息或键盘聚焦后即时显示。用户消息可以编辑并在新分支重发，随后自动展示新分支。新请求只使用该消息之前的上下文；旧输入、回复和分支关系保留在会话日志中。运行中先停止再编辑。待执行队列也可编辑；若另一页面已修改同一项，保存会提示冲突并保留当前草稿，取消后重新编辑可载入最新内容。

刷新页面后在左侧工作区树选择已保存会话继续查看；旧会话位于“未分配工作区”，时间显示创建时间，超过24小时后按本地日期MM-DD展示，悬停可见完整时间。删除会话实际执行归档并从列表移除，保留JSONL会话事实及原分支内容以维护历史完整性；它不是彻底擦除个人数据的入口。

会话数据库保存在原应用profile的`data.sqlite`，JSONL另放在仓库根目录的`.my-pi-harness/sessions/<profile标识>/<会话ID>.jsonl`，开发和正式运行采用相同规则。独立安装包启动时通过`MY_PI_HARNESS_SESSION_LOG_ROOT`指定仓库中的`.my-pi-harness`绝对路径。profile标识由数据库目录的完整路径摘要生成，Electron与独立daemon各自隔离；自定义profile不改变默认日志根。JSONL是会话事实源，SQLite保存配置与可重建查询投影；缺失已有会话日志时明确报错，不从SQLite反向补造日志。

JSONL保存会话执行事实，包括恢复所需的私有模型数据，不应作为公开分享文件；附件保存在独立内容文件中，完整备份需要同时保留附件与配置。写入先持久日志再更新SQLite；失败时停止后续持久写入，修复后重启校验恢复，不自动重做模型或工具副作用。

点击会话右上角“对话日志”即可下载`<会话ID>.jsonl`。运行中也可以下载，文件保留请求开始时已保存的完整记录，包括该会话全部分支；之后生成的内容需要再次下载获取。下载失败时页面显示原因，可再次点击重试。
