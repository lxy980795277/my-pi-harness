# 使用模型与会话

M1提供文字对话、配置与认证、停止、持久队列和历史分支。M2新增工作区与有审批的工具执行，操作见[工作区与工具](workspace-execution.md)。附件、MCP、子Agent、记忆和Computer Use仍在后续里程碑。

## 进入工作台

从仓库运行 `pnpm dev` 后打开5174页面，填写终端的一次性配对码；`pnpm dev:desktop` 打开的桌面窗口通过其私有启动链自动授权。只启动一种开发入口即可。已经进入工作台的页面可生成另一个浏览器的配对码；它10分钟有效且只消费一次。退出本机授权后重新配对，桌面也可重启建立新的窗口授权。

## 配置模型

点击侧栏底部用户信息卡片，进入「设置 → 模型」。内置厂商仅保留OpenAI（原Codex legacy目录）、Anthropic、Google、DeepSeek、MiniMax和Kimi（Kimi Coding）；其他服务可通过自定义Provider接入。内置厂商已经列出，直接在对应卡片点击「配置」完成认证；开关控制其是否参与后续模型选择，点击「模型」查看Pi提供的只读目录。

自定义服务使用「添加 Provider」，填写名称、具体协议和Base URL，选择是否需要API Key。可以先保存Provider，再在其「模型」弹窗添加模型ID、上下文和输出限制、推理能力。远端要求HTTPS；本机显式回环服务可以用HTTP。OpenAI兼容服务通常填写包含 `/v1` 的地址；Anthropic填写根地址，SDK会追加 `/v1/messages`。无需Key的本机服务关闭Key要求，实际请求不携带占位认证。

密钥在Provider配置弹窗内填写和保存，提交或关闭后清空输入；已有凭据只展示脱敏状态。密钥与OAuth凭据留在profile专属系统凭据库，不保存在会话数据库。若系统凭据库不可用，服务明确报错，不改用明文文件。

在「模型」弹窗对具体模型发起连接测试，它会产生一次真实短模型请求。保存成功只表示配置已接受，测试结果单独显示。使用真实供应商时该测试可能计费；未通过测试的自定义配置仍可编辑。

支持OAuth的内置Provider在配置弹窗内提供登录入口。按其中的地址、设备码或输入挑战操作；桌面通过系统浏览器打开所属授权流程地址。关闭Provider配置或设置弹窗会取消其未完成授权；成功后关闭配置并刷新厂商状态。已有认证可以退出后切换方式。

在模型设置顶部选择默认模型与思考等级，后续新会话使用这组设置。默认配置失效时重新选择；当前会话和正在运行的请求保持其原有选择。关闭设置回到原会话，草稿与已保存历史保留。

可选GitHub应用身份不影响普通本机使用，需要应用所有者先配置GitHub client ID，浏览器授权码方式还需client secret，设备码方式需在GitHub应用设置中启用Device Flow；它与GitHub Copilot模型认证不是同一功能。

## 对话、停止与输入队列

点击左侧“新对话”，直接在居中输入框输入文字，首次发送才创建会话。输入框下方可选择工作区、审批策略与对话模型；默认从已保存的模型偏好开始，也可明确选择其他模型。时间线呈现回复和推理内容，中心区域滚动，输入栏保持在底部。会话设置可以修改名称和后续Run的模型/推理级别；进行中的Run保持已接受参数。

回复进行中可以提交跟进或引导输入。跟进在当前回复后继续，引导中断当前模型请求并继续同一个Run。待执行面板可查看、修改和删除尚未消费的输入。停止会取消运行并保留未消费队列；恢复需要展开面板并明确继续。发送普通新消息不会偷偷恢复旧暂停队列。

恢复队列沿用接受时记录的Provider/model；如已经切到编辑后的新分支，先切回原分支。服务失败或异常退出后不会自动重发请求，重新打开会话可以查看已保存部分及interrupted状态，再决定是否继续。

## 编辑、历史与归档

用户消息可以编辑并在新分支重发。新请求只使用该消息之前的所选分支上下文；旧输入和回复保留在历史分支中，通过历史分支选择器查看。运行中先停止再编辑或切分支。

刷新页面后在左侧工作区树选择已保存会话继续查看；旧会话位于“未分配工作区”，时间显示创建时间。删除会话实际执行归档并从列表移除，保留SQLite事件以维护历史完整性；它不是彻底擦除个人数据的入口。

先配置自己的OpenAI兼容服务，验证连接并发起一次文字对话，再检查刷新、停止与队列、编辑分支和重启。本次设置变更的证据见[M1.6验证记录](../04_FEATURES/202610140900_feature_model-settings/verify.md)，原有会话行为见[M1验证记录](../04_FEATURES/202610131100_feature_model-session/verify.md)；keyless测试使用隔离的合成服务，不证明所有真实账户都已验证。
