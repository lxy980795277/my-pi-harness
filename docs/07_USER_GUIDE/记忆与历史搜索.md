# 记忆与历史搜索

长期记忆用于在后续对话沿用已保存的偏好、事实和约定。历史搜索用于找回原来的讨论，两者互不替代；搜索结果和Agent的一句「记住了」都不代表已保存记忆。

## 保存和使用记忆

在对话中说「记住，我希望回答先给简洁中文结论」，Agent可以直接保存，无需再进设置确认。要手工录入，打开用户菜单→设置→「记忆与搜索」，点击「添加记忆」。选择当前用户或当前工作区，填写正文和类别，再选择采用方式；只有已选工作区时才提供工作区选项。

- 固定采用：适合回答语言、项目规则等需要持续沿用的约定。
- 相关时采用：适合只在有关问题出现时使用的项目事实，允许本次没有匹配项。

有工作区的项目事实优先保存在该工作区；当前用户范围可供其他主对话使用。也可以hover一条完整消息，点击「保存到长期记忆」，编辑准确正文后人工保存。

「使用记忆」默认开启，关闭后仍可管理，但新的模型请求不会自动采用或查询记忆。子任务默认只使用获准工作区记忆，用户范围的条目需要主Agent显式转交。

在记忆列表中编辑、停用或忘记条目；同时编辑发生冲突时需要先查看当前内容，再决定如何保存。固定内容超过容量时会明确提示，可减少固定条目或改为相关方式。忘记影响后续尚未交给模型的请求，不删除过去回答和会话日志。

点击输入框下面的上下文占比，打开「上下文与工作状态」，在「上下文」中查看「本次采用的记忆」及当时正文，也会提示当前已修改、停用或忘记。子任务详情也有对应采用区域。该记录说明过去的实际请求，不用当前正文替换历史内容。

## 从对话中学习与管理

「从对话中学习」默认开启。当它与「使用记忆」都开启时，Agent可以在正常对话里保存稳定偏好、长期约定和事实；临时任务状态、秘密及引用资料不应自动学习。学习是否发生由Agent在正常工具循环中判断，不是每条消息都会保存，也没有回答结束后的额外后台提取。

聊天中的保存、学习和修改使用普通工具行；展开可查看实际结果，不需要到设置审阅候选。明确说「修改刚才的偏好……」可直接纠正。明确要求忘记时沿当前工具审批策略处理，完全访问模式可直接执行。

关闭「从对话中学习」后不再自动学习，明确要求记住或纠正仍可以执行；关闭「使用记忆」还会阻止自动学习。设置中可查看、编辑、停用或忘记已保存的条目。自动学习的偏好/约定默认固定采用，事实默认相关采用，可以在管理页调整。

「有效记忆画像」按偏好、事实和约定展示已启用条目。它直接对应原记忆，编辑仍修改同一条目；页面只显示当前页，可以翻页和筛选，没有另存一份总结。

## 查找旧讨论

点击左侧「搜索记忆与对话」，选择对话或记忆并输入关键词。默认限定当前工作区的可见主对话；可以明确切换工作区、时间，以及包含历史分支、归档或子任务。结果会显示关键词或混合检索，以及索引覆盖是否完整。

打开结果后显示只读原文片段。当前对话的结果可以点击「定位到当前对话」，自动展开必要的回答过程并滚动到对应消息；历史分支、归档和子任务保持只读，不切换执行分支，也不要求停止当前运行。

使用「上一组消息 / 下一组消息」查看邻近内容，长正文用「本条上段原文 / 本条下段原文」继续阅读。来源已变化或不可用时重新搜索，不用另一段相似文本代替原文。

点击「引用此片段」会把准确来源加入当前输入框，保留原有草稿。检查引用预览后显式发送；也可以移除引用。一次最多引用4个片段，每片段最多8000字符。引用不会自动保存为长期记忆，也不会让模型取得整个其他工作区的搜索权限。

## 本地搜索资源

关键词搜索不需要准备模型。需要语义检索时，在设置→「记忆与搜索」的本地搜索中，找到「语义模型」一行点击「准备模型」；相关记忆自动采用还需要在「相关性复核模型」一行独立准备。资源准备会下载缺失文件，可以取消，两者状态分别显示。

准备好的资源保存在本机，普通查询不下载权重。离线或资源不可用时保留关键词搜索；未核验的相关记忆不会自动采用，固定记忆仍可使用。「重建索引」只重建搜索数据，不删除记忆或会话。
