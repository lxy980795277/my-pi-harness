# 工作区与工具

点击左侧“新对话”直接输入。输入栏下从左到右为上下文、工作区、批准方式、模型/思考等级和发送；上下文加号目前禁用，附件和引用在后续实现。首次发送生成会话，标题取首条消息摘要，不再先填写名称。模型可继承全局默认，也可在发送前明确选择。

## 工作区与历史

左侧“工作区”旁的加号添加已存在的项目文件夹：Electron中点击文件夹选择区打开系统选择器，或拖入一个本机文件夹；选中的路径只读，可再次点击更换。名称前的图标按钮可选择18个Lucide图标，保存后侧栏与对话输入栏同步展示，也可在编辑工作区时修改。浏览器可使用和编辑已有工作区，新增目录按本轮范围后续补齐，不再要求手工填写路径。

注册按真实路径保存，不会复制或删除项目文件；系统根、Home及其上级目录、与应用profile重叠的目录，以及`.ssh`、`.aws`、`.env*`等敏感路径不能作为工作区。省略显示名时取目录名称，过长的默认名截短至允许长度；保存的完整根路径不截断，明确填写的名称仍按长度限制校验。

目录行支持展开、重命名与移除；有未归档会话时需先处理这些会话，移除工作区不删除磁盘。文件工具使用工作区内的相对路径和正斜杠，例如`src/中文 文件.txt`；拒绝`..`、反斜杠、Windows设备名（如`CON`、`NUL`）、冒号数据流以及尾点/尾空格名称。这些通用限制在macOS也生效。

工作区下面显示各会话及创建时间。旧会话在“未分配工作区”，仍可对话；需要本地工具时应在新对话选择工作区。已有会话的工作区固定，不能通过切换输入栏给正在运行的任务换目录。

## 批准与工具结果

“请求批准”模式下，允许的工作区读取与搜索直接执行；文件写入/编辑、Shell和Web请求会显示工具卡，查看目标与调用参数后选择“允许本次操作”或“拒绝本次操作”。批准只对该次有效，越界路径和不允许的网络目标不会因此放行。“只读”禁止修改、Shell与网络POST，但可批准公网GET。

工具卡区分等待、运行、完成、拒绝、取消和失败。执行后可展开文本结果与文件Diff；修改前须先读取获取当前SHA-256，内容变化后旧批准不能覆盖新内容。PDF支持文本提取而没有OCR，图片只提供受限模型输入；二进制内容不显示为普通文本事件。

macOS Shell在无网络的OS沙箱中执行，不能读取应用凭据和敏感文件。Windows/Linux Shell当前不可用，会明确拒绝；Windows Shell专项按用户要求暂缓，本轮不进行该平台验收。文件和普通聊天的实际平台结果以验证记录为准。点击停止取消当前运行、审批和所属操作；重启后不会自动批准或重发中断副作用。

发送响应丢失时先检查左侧历史；应用会保留未确认请求关联，重试复用原请求。不要把连接成功或审批通过当成工具执行成功，具体完成状态以卡片和持久历史为准。
