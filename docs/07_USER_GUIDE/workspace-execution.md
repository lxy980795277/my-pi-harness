# 工作区与工具

点击左侧“新对话”直接输入。输入栏下从左到右为上下文、工作区、批准方式、模型和发送；上下文加号可上传附件，MCP可选择已发现的工作区工具，见[本地MCP](本地MCP.md)；Skill可选择本次使用的指令与资源，操作见[Skills与插件指南](Skills与插件.md)。首次发送生成会话，标题取首条消息摘要，不再先填写名称。模型可继承全局默认，也可在发送前明确选择；推理强度统一放在模型菜单顶部，具体操作见[模型指南](model-session.md#配置模型)。

## 工作区与历史

左侧“工作区”旁的加号添加已存在的项目文件夹：Electron中点击文件夹容器中央的“添加”按钮打开系统选择器，或拖入一个本机文件夹；选中的路径只读，可点击“更换文件夹”重新选择，容器空白不触发选择。名称前的图标按钮可选择18个Lucide图标，保存后侧栏与对话输入栏同步展示，也可在编辑工作区时修改。浏览器可使用和编辑已有工作区，新增目录按本轮范围后续补齐，不再要求手工填写路径。

注册按真实路径保存，不会复制或删除项目文件；系统根、Home及其上级目录、与应用profile重叠的目录，以及`.ssh`、`.aws`、`.env*`等敏感路径不能作为工作区。省略显示名时取目录名称，过长的默认名截短至允许长度；保存的完整根路径不截断，明确填写的名称仍按长度限制校验。

点击目录行只展开或收起会话列表；悬停时右侧显示更多与加号。点击加号进入新对话并选中该工作区，首次发送才创建会话。更多菜单提供重命名和删除；有未归档会话时需先处理这些会话，删除工作区只移除登记，不删除磁盘。文件工具使用工作区内的相对路径和正斜杠，例如`src/中文 文件.txt`；拒绝`..`、反斜杠、Windows设备名（如`CON`、`NUL`）、冒号数据流以及尾点/尾空格名称。这些通用限制在macOS也生效。

工作区下面显示各会话及创建时间。旧会话在“未分配工作区”，仍可对话；需要本地工具时应在新对话选择工作区。已有会话的工作区固定，不能通过切换输入栏给正在运行的任务换目录。

## 批准与工具结果

批准方式提供三个选项，选择只影响后续运行：

- 请求批准：允许的工作区读取与搜索直接执行，文件修改、命令和Web请求逐次询问。在工具卡查看参数后允许或拒绝本次操作。
- 帮我批准：独立AI使用当前会话模型复核待批操作；明确允许才执行，明确拒绝不执行，不确定、失败或超时转人工确认。这会产生额外模型请求。
- 完全访问权限：自动批准工具调用，macOS命令以当前用户权限运行且不受OS沙箱限制；仍有超时、输出上限和停止控制，不进行系统提权。

文件工具始终限制在注册工作区。旧“只读”会话保留原策略，禁止修改、Shell与网络POST；打开新菜单不会自动改变它。

工具行区分AI复核、等待人工、运行、完成、拒绝、取消、失败和结果未知，并展示审批来源与理由。执行后可展开文本结果与文件Diff；修改前须先读取获取当前SHA-256，内容变化后旧批准不能覆盖新内容。PDF支持文本提取而没有OCR，图片只提供受限模型输入；二进制内容不显示为普通文本事件。

请求批准和帮我批准的macOS Shell保持无网络OS沙箱，不能读取应用凭据和敏感文件；完全访问权限下的Shell可以访问当前用户有权访问的工作区外文件和网络。Windows/Linux Shell当前不可用，会明确拒绝；Windows Shell专项按用户要求暂缓。点击停止取消当前运行、审批和所属进程组；脱离所属组的恶意后代不在现有回收保证内。重启后不会自动批准或重发中断副作用。

发送响应丢失时先检查左侧历史；应用会保留未确认请求关联，重试复用原请求。不要把连接成功或审批通过当成工具执行成功，具体完成状态以卡片和持久历史为准。
