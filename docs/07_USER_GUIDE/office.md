# 本地办公文档

安装 Documents、PDF、Spreadsheets 或 Presentations 插件，选择或让 Agent 加载对应 Skill。Skill 提供操作流程、格式知识和脚本资源；生成、编辑和验证使用普通受监管命令，交付使用 `publish_artifact`。账号授权、工具批准和 Skill 加载分别管理。

## 准备依赖

使用已安装的 Python 3、当前 Skill 的 `requirements.txt` 以及需要的系统字体。可以在工作区显式创建虚拟环境并安装这些公开依赖；应用不会静默下载或安装软件。将 `MY_PI_HARNESS_PYTHON` 设置为解释器的绝对路径后重启 daemon；受监管命令可读取同名环境变量，页图工具也使用该配置。没有配置时，Skill 先检查可用的 `python3`，页图工具检查标准安装位置。

每个 Skill 都先执行自己的 `dependencies` 子命令，报告缺失 Python 包和转换器。DOCX/XLSX/PPTX 转 PDF 另需已安装的 LibreOffice。缺少依赖应明确说明；安装依赖仍需要普通命令所需的权限。安装包不包含 Python、LibreOffice 或所有字体。

## 工作流程

1. `load_skill` 返回本次冻结资源的 `resourceDirectory`，Agent 以它作为 `SKILL_ROOT`，按需读取参考文件。资源目录供受限进程只读使用；工作文件、临时创作脚本和输出保存在工作区。
2. `run_command` 启动命令，默认等待最多十秒。返回 `running` 时保留 `commandId`，通过 `wait_command` 等待并按返回游标读取增量输出；`stop_command` 停止自己任务所属的命令。
3. 检查退出码、错误和截断信息，再重新打开最终文件。`read_document` 读取正文；`view_image` 和 `view_pdf_page` 提供实际图像，需要视觉模型。正文正确不能证明排版正确。
4. 生成和验证完成后调用 `publish_artifact`。可提供同任务已成功结束的 `producerCommandId`；不提供时只表示冻结了当前文件字节，不能证明生产命令已经结束。

展开发布工具详情可下载产物。下载使用宿主登记的 artifact ID 和 SHA-256；源文件之后改变或删除，下载仍返回发布时的不可变快照。stdout、Markdown 文件路径和工具自报 hash 不会自动变成可信下载。主对话和子任务都使用同一交付方式。

## 格式能力和验证范围

- Documents 的 CLI 支持精确替换、真实修订及接受/拒绝、批注、脚注、书签、域、内容控件和受限模板合并。普通创作用 Python 库生成原生段落、表格、图片和页眉页脚；辅助脚本拒绝覆盖既有输出，保留输入文件。目录、交叉引用和页码域需要办公应用实际更新。
- PDF 支持自动分页、中文长表、重复表头、页面操作、支持的文本/checkbox/choice 表单、外观、受限修复及文本扁平化。加密、签名、XFA 和活动内容明确拒绝；覆盖区域仍保留底层内容，不能作为安全脱敏。
- Spreadsheets 检查公式、缓存、错误单元格、表格与原生图表；真实重算依赖已安装的办公引擎。仅保存公式不能证明计算结果正确，活动公式和外部链接不能直接交给转换器。
- Presentations 使用原生文本、表格、图表和模板部件，检查页面尺寸及几何边界；文字溢出、重叠和视觉质量仍需实际转换及逐页检查。

受限命令没有网络，资源目录只读；只读角色的工作区也不可写。完全访问权限使用宿主用户权限，不能据此声称任意命令受到上述文件隔离。自写脚本应遵守另存为新文件的流程，但任意已授权命令的实际副作用由该命令决定。没有转换器、视觉模型或实际重算时，必须明确列出未验证项，不能把脚本退出成功当作完整质量验收。
