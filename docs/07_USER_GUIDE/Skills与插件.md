# Skills 与插件

Skills 为某类任务提供可复用的指令和资源。插件把 Skills 与 MCP Apps 组合安装；安装完成后仍需要分别连接账号、授予启动信任和处理工具审批。

## 创建、安装和选择 Skill

打开用户菜单中的「设置 → Skills」。默认显示当前 profile 的用户作用域，也可以选择一个已注册工作区查看项目和兼容目录的 Skills。用户作用域的安装数据位于 `<profile>/skills`；默认profile使用系统应用数据目录，可显式配置，具体路径见[启动配置](../01_ARCHITECTURE/overview.md#启动配置)。它与仓库根目录中的会话JSONL分别管理。

点击「创建 Skill」，填写小写短横杠名称、描述和指令后保存。也可以点击「从 GitHub 安装」，填写公开仓库的用户/组织、仓库名、分支/标签/提交和 Skill 目录；服务先固定提交，再校验和安装该目录。安装不会执行仓库脚本，同名安装不会覆盖。下载过程中可以取消；安装结果不明确时先检查列表再重试。

点击列表中的名称可以读取完整指令及资源索引，点击资源可查看正文或图片。桌面可以打开注册目录，浏览器可以复制经过校验的目录路径。启停影响新选择；卸载只操作明确属于本应用的安装，不删除兼容发现的其他项目源文件。插件提供的 Skill 应在插件页管理。

回到对话，在输入框「+ → Skill」选择本次使用的指令。选择版本会随发送固定，旧 Run 的正文和资源不随源文件修改。运行中和未确认的提交保持原选择；过期选择需要明确移除或重选。编辑历史消息、排队输入时也可以查看或修改相应 Skill 选择。Skill 声明的工具仍受当前审批、计划模式和工作区规则限制。

## 安装和管理插件

打开「设置 → 插件」，按在线服务或办公文档筛选，点击安装。插件页显示它拥有的 Skill 和 MCP App，可以整体或逐项启停。App 的状态来自对应配置与授权事实；「管理 MCP」处理服务启动与工具目录，「管理连接」处理第三方账户。启用一个组件不会自动授予账号或工具权限。

Google 插件分别提供 Drive、Docs、Sheets、Slides 与 Calendar Apps；其他在线服务按自己的账号和客户端配置要求连接。办公插件使用工作区内的新输出文件，依赖检测和验证结果见[办公文档指南](office.md)。真实供应商账户状态应在连接或 MCP 页核对，不能仅根据插件安装状态判断可调用。

活动 Run 仍使用 Skill 资源时，卸载会明确拒绝。先停止并等待当前运行结束，再执行卸载。停用后重新启用或卸载后重装，需要新选择和授权；旧 Run 的授权不会恢复，也不会自动重放外部操作。
