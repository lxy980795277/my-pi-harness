# 上下文、计划与检查点

本页说明M3界面入口与行为；实施和验收范围见[功能Spec](../04_FEATURES/202610151655_feature_m3-context-interaction/spec.md)，各平台与真实供应商结果见[验证记录](../04_FEATURES/202610151655_feature_m3-context-interaction/verify.md)。

## 带文件提问

点击输入栏左下角`+ → 上传文件`添加文本、图片、PDF或受支持的Office/OpenDocument文档。菜单中的MCP可选择已发现工具，见[本地MCP指南](本地MCP.md)；Skill选择及创建、安装操作见[Skills与插件指南](Skills与插件.md)；工作区文件引用不提供添加入口，已有历史引用仍可预览。每条消息最多8个附件，文件卡可预览或从草稿移除，也可只发送附件。已发送附件随历史、队列和分支保留，刷新后仍可预览，未发送草稿附件不保证刷新保留。

文本上限256000字节，图片2MiB，PDF 8MiB。PDF预览和模型输入使用提取文本，最多20页、约100000字符，无OCR；扫描件可能没有可用正文。图片需要支持图片输入的模型。工作区引用保存添加时的内容，之后修改或删除原文件不会改变已添加内容；需要新版本时重新添加引用。

## 查看规则和上下文

打开已有会话，点击输入框下方的“上下文”占比文字，进入“上下文与工作状态”。“上下文”页显示最近Run的估算输入、模型窗口、输出预留和裁剪条数；这些数字是估算，不是供应商账单。

在项目根目录放置AGENTS.md，下一次运行会加载；引用子目录文件时还会读取路径上的下级AGENTS.md。同目录内下级规则优先，应用权限始终生效。“生效规则”可查看最近一次运行使用的来源与正文，“查看工作区当前规则”只预览当前根规则。改动规则在下一次运行生效，旧运行内容保持原样。

每次模型请求前都会检查预算，必要时精简旧工具结果、生成摘要或裁剪历史，保留最新输入和完整工具调用/结果。同一次运行中也可多次压缩，完整历史仍可查看。也可先停止Agent，再点“压缩上下文”；摘要使用当前配置模型，实际调用时可能产生供应商费用。摘要生成失败可使用有界本地摘要，最终仍超限则停止发起模型请求；最新输入或附件本身过大时，按提示缩短内容或减少附件。

“上下文检查点”保存摘要版本，可选择比较基准和查看版本，再点“使用所选版本”并确认。切换后以该摘要继续，切换前的历史尾部退出模型上下文，完整原始记录保留；该操作不创建会话分支。

## 回答问题和管理计划

Agent需要用户决定时，会直接显示提问卡。按每题允许的方式单选、多选或输入自己的回答，完整填写后点“提交回答”，原运行继续；也可“取消提问”，将取消结果交回Agent。“提问记录”页保留回答状态。停止或重启后旧等待不会自动继续；普通聊天即使没有工作区也能提问、维护计划与任务。

新对话可在首次发送前选择Plan模式；已有会话可在Agent空闲时通过“计划与任务”页切换为“Plan · 只规划”。该模式允许读取资料、制定计划和任务，禁止文件修改、Shell和Web POST。

Agent提交计划后会在对话中等待审核。点击“批准并执行”会让同一次运行继续，无需再次发送消息；填写修改意见后点“提交修改意见”，Agent会在原运行中修订计划；“取消审核”保持规划模式。计划批准不替代文件、Shell或Web工具的具体审批。Agent空闲时可以编辑任务和状态；任务关联的步骤必须存在，替换计划前需保留这些步骤或先更新、清理任务关联。

## 保存、比较和恢复检查点

先停止Agent，在“会话快照”页填写“快照名称”，点击“创建会话快照”。选择“比较基准”和“比较目标”，查看消息前缀、规则、摘要、上下文起点、计划和任务的变化；选定目标后点击“恢复目标快照”并确认。恢复会创建新分支，保留原分支的后续历史，不自动执行队列。

同页提供两种独立重置：“重置任务状态”只清计划和任务，保留上下文与摘要；“重新开始上下文”设置新的历史起点，清规则、用量、摘要、问题和未消费队列，保留模式、计划、任务及可查看的历史。摘要切换、快照恢复和两种重置都不会撤销磁盘文件修改、Shell或外部请求。
