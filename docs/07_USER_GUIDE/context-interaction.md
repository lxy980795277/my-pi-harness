# 上下文、计划与检查点

本页说明M3界面入口与行为；实施和验收范围见[功能Spec](../04_FEATURES/202610151655_feature_m3-context-interaction/spec.md)，各平台与真实供应商结果见[验证记录](../04_FEATURES/202610151655_feature_m3-context-interaction/verify.md)。

## 带文件提问

点击输入栏左下角`+ → 上传文件`添加文本、图片或PDF。菜单中的MCP、Skill为后续功能占位，暂不可用；工作区文件引用不提供添加入口，已有历史引用仍可预览。每条消息最多8个附件，文件卡可预览或从草稿移除。正文和文件准备好后发送；已发送附件随历史、队列和分支保留，刷新后仍可预览，未发送草稿附件不保证刷新保留。

文本上限256000字节，图片2MiB，PDF 8MiB。PDF预览和模型输入使用提取文本，最多20页、约100000字符，无OCR；扫描件可能没有可用正文。图片需要支持图片输入的模型。工作区引用保存添加时的内容，之后修改或删除原文件不会改变已添加内容；需要新版本时重新添加引用。

## 查看规则和上下文

打开已有会话，点击输入区附近的“上下文”用量入口，进入“上下文与工作状态”。“上下文”页显示最近Run的估算输入、模型窗口、输出预留和裁剪条数；这些数字是估算，不是供应商账单。

在项目根目录放置AGENTS.md，下一次运行会加载；引用子目录文件时还会读取路径上的下级AGENTS.md。同目录内下级规则优先，应用权限始终生效。“生效规则”可查看最近一次运行使用的来源与正文，“查看工作区当前规则”只预览当前根规则。改动规则在下一次运行生效，旧运行内容保持原样。

长对话会按预算裁剪旧完整轮次，原历史仍可查看。接近阈值时下一次运行会尝试生成摘要，也可先停止Agent，再点“压缩上下文”；摘要显示在同页，失败保留旧摘要和历史。摘要使用当前配置模型，可能像正常聊天一样产生供应商费用；只有实际调用该模型时才发生这类请求。最新输入或附件本身过大时，按提示缩短内容或减少附件。

## 回答问题和管理计划

Agent需要用户决定时，会直接显示提问卡。选择选项或输入自己的回答，再点“提交回答”；也可“取消提问”。“提问记录”页保留回答状态。停止或重启后旧等待不会自动继续；普通聊天即使没有工作区也能提问、维护计划与任务。

新对话可在首次发送前选择Plan模式，让第一轮只规划；已有会话可在“计划与任务”页将工作模式切为“Plan · 只规划”，让Agent读取资料、制定计划和任务；该模式不能写文件或执行Shell。Agent停止后可以编辑计划和任务、调整任务状态。点击“批准计划并切换执行”后，再发送输入开始执行；文件修改、Shell和Web操作仍按所选批准方式授权。批准计划本身不会执行任务。

## 保存、比较和恢复检查点

先停止Agent，在“检查点”页填写名称并创建检查点。选择“比较基准”和“比较目标”，查看消息前缀、规则、摘要、上下文起点、计划和任务的变化；选定目标后点击“恢复目标检查点”并确认。恢复会创建新分支，保留原分支的后续历史，不自动执行队列。

“重置工作状态”清理当前上下文选择、摘要、计划、任务和未消费队列，保留可查看的聊天历史；之后的新运行从重置位置继续。检查点恢复和工作状态重置都不会撤销磁盘文件修改、Shell或外部请求。
