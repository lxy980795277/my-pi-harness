# 0.19.1

日期：2026-11-09。属于M0及既有M1–M5共享规则与状态归属治理，按用户授权本地提交，不推送或对外发布。M6继续仅规划。

## MCP与账户

独立高级账户引用官方MCP时不再要求安装或启用同供应商插件；插件App仍核对精确pluginOwner、组件及Server引用。目录展示、候选、冻结和执行统一匹配当前身份、配置、定义指纹与控制代次的只读grant，执行继续校验冻结grant ID、控制revision和精确参数hash。

CatalogCache统一管理目录恢复、发现、显式刷新、发布和失败状态。刷新跳过旧快照，与相同授权的在途发现共享任务；调用者取消只停止自己的等待，实际工作继续受截止、撤销及关闭约束。失败清理旧内存和持久目录，物理连接回收诊断独立保留。配置提交后的本地/远端凭据清理尝试全部不再使用的引用，再报告安全错误，包含OAuth客户端秘密替换和删除，不宣称回滚已提交配置。

## 运行时、Skill与网络

队列私有接受数据由protocol/internal唯一定义，storage在持久写入、回放和读取时校验，并向运行时返回明确类型，删除同进程重复schema及校验。移除RuntimeStore未使用的恢复端口，实际启动恢复仍归宿主。

SkillCatalog提供全部有序来源和内容，daemon使用单次发现快照计算启用及有效覆盖；详情和冻结消除重复目录扫描，冻结时仍重读所选来源验证hash及当前授权。DNS全结果验证、取消和socket地址固定由sandbox共用，Web及MCP/OAuth各自的URL、凭据、网关、重定向和正文策略保持独立。

## Web与附件

模型Provider的OAuth服务、轮询、挑战、类型和面板统一归models，应用登录仍归auth；模型授权完成只刷新模型配置及流程。附件格式、MIME和字节上限由protocol统一声明，文件选择、预检与宿主解析共用，签名、UTF-8、解压及路径检查仍由宿主执行。会话日志、产物和MCP配置导出共用按目标身份拥有的Blob下载生命周期，各领域继续取得和校验字节及命名。

根产品版本与APP_VERSION同步为0.19.1；公开协议25、SQLite10和Session格式保持，不需要数据迁移或清理，内部私有包不独立升版。
