# 0.6.0

日期：2026-10-20。完善M1–M3的对话渲染与交互，M4仅保留已确认的任务规划并继续暂缓。本次为本地代码提交，未推送或对外发布。

## 对话渲染与交互

- 助手与思考使用公开Streamdown、官方CJK插件和按需Shiki高亮，支持流式Markdown、代码复制与中文标点相邻强调。保留原始消息；禁用模型HTML，限制外链协议，图片引用不自动请求远程内容。
- 消息使用TanStack Virtual、稳定业务key、动态测高与有限overscan。阅读列和输入框共用896px宽度，输入区调矮；Markdown采用整数px排版，保留上滑阅读、回到最新、停止和排队。
- 工具以“图标 名称 · 内容”单行展示，hover或键盘焦点切换展开箭头，执行中在行首显示loading；详情按需展开，待审批操作持续可见。
- 按用户输入汇总一次回答，在最后工具之后统一提供正文复制、实际token用量、总耗时及完成时间；工具前后正文不会各自重复出现复制按钮。同一Run内多个用户输入分别结算，历史缺失用量不补造为零。
- 输入框下方常驻显示上下文占比与总对话次数，仅统计当前分支已接受的用户消息；上下文详情、人工提问与计划审核保留。运行中发送默认排队，移除原策略选择器。

## 会话同步与日志

- SSE以权威基线和有序增量批次同步正文、思考及状态，缺口、重连、分支切换和终态进行校准。慢连接受背压与超时管理，正常注销结束HTTP流，异常及背压连接强制关闭；服务协议不兼容和首基线缺失明确反馈。
- 供应商usage和助手完成时间写入已有消息完成事实，SQLite投影与JSONL重放保留这些字段；未记录的历史统计保持缺失。
- 全宽header左侧显示标题，右侧下载已提交的原始JSONL；移除重复模型设置、分支选择及删除入口。下载受应用登录保护，以请求开始时的完整已提交批次固定字节范围，包含该会话所有分支及私有重放事实，不是脱敏分享文件。

- 受限外链桥校验调用窗口、主frame、来源及HTTP(S)参数，通过系统浏览器打开链接，卸载时清理IPC；默认拒绝新窗口的策略保留。
- 移除已失去消费者的顶部设置组件、Hook与服务包装，同步架构、API、使用说明及技术文档。M4文档仅拆分任务，没有实现MCP或其他M4能力。
