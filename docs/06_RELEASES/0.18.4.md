# 0.18.4

日期：2026-11-06。属于M0及既有M1–M5职责治理，按用户授权本地提交，不推送或对外发布。M6继续仅规划。

## 插件与接入

新增私有plugins包，统一拥有插件声明、随包资源、安装/启停/更新/卸载、账号授权生命周期和网关规则。daemon通过仓储、凭据、Skills及MCP窄接口装配，保留HTTP与宿主配置；tools继续拥有通用Skill引擎和27个工具，插件中的Skill正文与脚本随插件包部署。

integrations集中MCP、网络和通用OAuth，插件与高级账户共用授权码、PKCE、Token交换及刷新机制，保留独立账户/安装归属和供应商策略。认证与响应处理沿用SDK校验，保留固定安全诊断、取消、撤销和刷新行为。本地向量Worker及Transformers生产依赖归daemon。

## 协议与存储

protocol根入口提供公开跨端数据，internal入口提供宿主冻结绑定、恢复材料及私有插件记录；Renderer与公开协议不能引用internal。EventInput、RequestAcceptance及SessionCreateRecord唯一定义，移除Storage类型转发文件与别名，所有消费者同步迁移。

SessionQueries、SessionRecovery和ArtifactRepository分别拥有查询、启动重建及产物引用。ProfileStore保留profile锁、资源生命周期、唯一事务、JSONL fsync及失败冻结；会话创建与事件追加复用SessionEventCommit。公开HTTP/SSE字段、会话落盘格式和数据恢复语义保持，不清理用户数据。

根产品版本与APP_VERSION同步为0.18.4，公开协议24、SQLite10保持，私有包维持0.0.0。源码exports、Node/tsx运行与静态资源部署方式保持；旧插件实现路径及tools/plugins出口移除，仓库消费者和部署检查已同步，无兼容转发层。
