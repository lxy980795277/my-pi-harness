# 0.22.0

日期为2026-11-14。本次交付M7执行追踪、统一用量、原生文件变更和完整会话归档，并包含安装候选与治理修复。功能实现和本机工程检查已收口，内容质量和平台发布条件未全部通过，不代表M7完整发布验收完成。

## 执行与用量

主子对话、审批复核及压缩模型请求共用独立请求身份和生命周期。会话轨迹支持任务树、筛选、冻结分页及按需查看最终输入、工具正文和图片；请求与回答归属在实际消费输入时冻结。冻结历史页与已完成详情不再被后台事件反复刷新，首响应记录Provider回调、非start事件或终态中最早的宿主观测，不冒充网络TTFB。

回答、子任务和会话按唯一请求聚合Token、等待及执行时间，区分墙钟与累计模型耗时、已记录与未知部分。费用使用请求时冻结的Pi目录规则估算；自定义零价和未知外部服务不视为免费，不冒充供应商账单。

## 文件变更

write_file与edit_file由宿主统一记录不可变前后像，支持查看差异、逐项或按回答批量撤销重做。操作检查当前文件、权限、路径身份和修改链，保留冲突、取消及未知结果；启动恢复只观察，不重放写入。归档会话中的未结算操作仍安全收口，避免阻塞启动或遗留共享待发布锁。

Shell、MCP和办公脚本的任意修改不纳入原生撤销。导入历史保持只读；批量操作资格来自本机记录及完整查询范围，不由当前分页、展示文案或重新绑定自动授予。

## 会话归档

完整tar.gz归档包含冻结日志的全部分支、子任务、可达附件、产物、文件前后像和历史Skill资源，附带manifest、长度、hash及非秘密依赖说明。原始JSONL下载保留，导入只接受完整归档；未保存的原始办公附件二进制不声称已经备份。

导入先预检资源、格式和ID冲突，再由storage发布及恢复。旧Run、队列、审批和文件操作不会自动执行，历史记忆不写入当前记忆库；继续前须显式绑定本机模型和工作区，旧插件授权不迁移。

## 桌面与治理

新增macOS DMG、Windows NSIS候选及安装路径smoke，产物明确区分unsigned与signed。构建校验签名凭据，独立验收主机只选择模式并检查实际签名；失败不降级。daemon统一解析日志根，源码默认使用仓库日志，安装环境默认使用当前profile下的日志，桌面不再重复推导。

清理Usage无职责转发、重复临时目录创建和过期文档，保留请求、用量、文件发布、归档发布及界面状态各自的拥有者。修复归档文件恢复、导入操作资格、Trace刷新、首响应竞态和安装验收配置问题。

## 协议与数据

产品版本和APP_VERSION同步为0.22.0，公开协议29升至30、SQLite schema16升至20。Web、daemon及桌面须同步更新，真实数据保留，现有数据库按已校验的增量迁移升级；旧请求没有的新指标继续显示未知，不伪造历史用量或耗时。旧构建不能降级读取新schema。

已有数据库继续使用原日志根；开发与安装的默认根不同，需要保持MY_PI_HARNESS_SESSION_LOG_ROOT或按完整归档迁移，不能仅改默认根后重建旧数据。卸载或移除应用不主动删除业务profile。协议和迁移注意事项见[文件变更](../03_API/file-changes.md)、[会话归档](../03_API/session-archives.md)与[发布政策](overview.md#发布证据)。
