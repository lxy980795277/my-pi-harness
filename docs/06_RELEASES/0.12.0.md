日期：2026-10-28。本次为输入栏与会话存储整理的本地提交，不推送或对外发布；属于M1/M3维护和M4收尾，M5尚未开始。

## 输入栏与模型选择

移除新旧会话、工作面板和检查点中的执行/Plan模式，删除创建参数workMode、工作状态/编辑mode，以及草稿、上下文和MCP的相关模式分支与只规划限制。结构化计划、Todos、人工提问和同Run计划审核保留，工具仍按当前审批策略、精确授权与工作区规则执行。

推理强度位于模型菜单顶部的统一子菜单，下面按服务商选择模型。输入栏只保留一个显示当前模型和强度的入口；可选档位来自当前模型能力，关闭-only模型仅提供关闭。菜单基于维护中的Radix原语处理键盘、焦点和碰撞避让，复用现有品牌资源、主题和CSP设置。

## 会话日志与校验职责

JSONL新批次只写records/checksum，删除外层批次version。读取先验证原始对象全部字段的checksum，再解引用和选择当前公开字段；旧批次、record/envelope元数据及废弃业务字段不阻断结构可读日志，历史字节保留，新追加采用无版本批次。

事件payload schema集中管理并供读取和业务投影复用，创建会话、Run和完成消息使用共享父schema，清除重复子对象校验及散落声明；codec与工作投影共享私有请求schema。公开字段清理在原请求baseline保存之后进行，不填默认值、转换类型或改写privateData。必要结构、类型、关系、连续seq、大小和checksum继续校验，HTTP与新写业务仍严格。

## 协议与现有数据

公开协议17升至18，旧workMode/工作mode参数不再接受，前后端须同步更新并完整重启。SQLite schema8、事件envelope1和私有codec版本保持。JSONL无外层版本号不表示任意历史编码均可读；必要数据损坏或codec不符合要求仍拒绝，旧程序也不承诺读取新批次。

没有迁移、重写或清理原会话、数据库、凭据或工作区。通过readonly SQLite backup及日志副本完成现有桌面会话隔离回放，恢复1个会话、14条消息和12条工具记录，原日志SHA-256保持一致，临时副本已清理。
