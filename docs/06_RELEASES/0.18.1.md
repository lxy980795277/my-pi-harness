# 0.18.1

日期：2026-11-06。属于M0构建/部署治理及既有M2–M5工具维护，按用户授权本地提交，不推送或对外发布。M6继续仅规划。

## 构建与运行

六个后端私有包和daemon直接导出src，开发、测试与生产统一使用实际package exports。daemon通过独立Node及生产依赖tsx运行源码，删除后端dist构建配置和源码覆盖别名。Web与Electron main/preload继续构建；协议及必要TypeBox代码打入桌面JS/CJS产物。

CLI、恢复、浏览器fixture、生产部署探针和桌面启动同步采用源码入口。daemon独立部署验证入口改为test:deployment，根test:artifact继续提供统一验收命令。后端相对导入保留.js，Web无后缀约定保持。

## 工具与插件

插件manifest、App声明、Skill及专属格式脚本归并至tools/src/plugins。共用办公支持和PDF页图支持按实际消费者归属，65份资产都有对应位置，保留12条精确共享hash及四个允许来源，快照、租约和撤销机制保持。

移除没有生产消费者的插件解析、贡献索引和skillRoot方法，以及无人读取的工具上下文字段；真实图片能力及权限判断保持。App声明只读取一次，再派生公开与宿主数据。27个工具的声明、顺序及加载元数据不变。

## 版本与验证范围

根产品版本与APP_VERSION同步为0.18.1，公开协议24、SQLite10及消息/会话格式不变，不清理用户数据。内部私有包保持0.0.0；其源码出口要求由tsx或相应构建器加载，不再提供后端dist入口。

[验证记录](../04_FEATURES/202611061105_refactor_source-runtime-plugin-assets/verify.md)包含全workspace类型/构建、完整静态检查、2014项源码测试通过及2项既有条件跳过、7项CLI/恢复/隔离部署检查，以及4条受控模型与合成OAuth浏览器链路。四个办公Skill在独立生产部署中的物化和CLI执行通过，macOS arm64实际应用目录打包与smoke通过，随包Node为24.20.0。

上述行为与桌面验证基于0.18.0候选实现；本次同步0.18.1提交元数据与发布记录，不重新打包，不将已有0.18.0应用目录标为0.18.1产物。Windows/Linux实际运行、真实供应商/OAuth、LibreOffice及完整Office视觉质量未重新验收；没有正式安装器、签名、公证或自动更新发布。
