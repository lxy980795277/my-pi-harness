# 0.15.0

日期：2026-11-01。本次升级Pi内核及模型适配，属于M0依赖治理与M1–M5维护；按用户要求本地提交，不推送或对外发布。M6继续仅规划。

## Agent运行时

Pi agent-core与ai精确升级为正式1.4.0，统一传递依赖并移除旧core→ai 1.1.0覆写。采用正式Provider协议及目录，不引入未发布源码、coding-agent、durable、codemode或新的消息管理层。原生Provider的显式baseUrl同时作用于模型请求和目录刷新；旧失效型号或不支持的推理档位明确拒绝，不自动替换用户选择。

所有模型lease统一应用请求身份，User-Agent标记产品和实际Pi版本，关闭Pi默认厂商归属头；主子Run、摘要、审批及连接探测共用此入口。保留keyless认证清理与显式模型headers优先级，不自动启用遥测。

## 工具与会话数据

Pi最终JSON解析错误在schema转换、审批和执行前反馈给模型；仍严格校验原始工具参数。错误关联当前assistant的原始参数对象，不按可复用的Provider调用ID缓存；模型可见错误有长度限制，完整原始信息私有保存，调用与结果成对落盘。

私有消息记录实际Pi SDK来源，runtime及storage按应用codec和字段验证，不以SDK版本作为同一应用格式的读取分支。保留完整消息、签名、argumentsError及既有主子Run、审批、队列、插件/MCP和取消语义；不清理用户数据或重写凭据。
