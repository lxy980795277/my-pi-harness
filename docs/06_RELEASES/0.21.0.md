# 0.21.0

日期为2026-11-12。本次交付DeepSeek联网搜索、网页正文与原始HTTP分工、独立服务凭据设置及相关代码治理，属于既有M2/M4维护。M6本地检索与M7范围保持。

## 联网工具

新增默认工具web_search，一次调用搜索一个问题，支持结果数量、原始问题、本地化IP与正文选项。web_fetch明确选择page或raw，page通过DeepSeek官方Fetch读取Markdown，raw执行受控原始GET/POST和精确插件网关请求。搜索与page按业务只读，raw POST保留副作用审批与角色限制。主子Run使用同一套宿主端口，所有插件Skill与测试消费者同步使用显式模式。

## 凭据与设置

设置新增“联网搜索”，使用独立的官方DeepSeek Key，存入当前profile的系统凭据库。页面只缓存配置状态，秘密提交后清空，保存和删除成功直接采用响应状态。更换或撤销Key取消旧代请求，Run取消、配置等待、产品期限和服务关闭贯通所属操作。

## 代码治理

官方服务适配、宿主凭据、模型工具和原始HTTP分别由integrations、daemon、tools及raw传输模块拥有。通用网络类型解除对MCP的依赖，宿主结果类型归protocol/internal，移除无消费者的公开结果schema和重复状态请求。修复搜索文本IPv6目标漏检、正文释放覆盖原错误、配置等待无法及时取消及完整输出超限，并补齐模型参数说明与Skill工具声明。

## 协议与验证

产品版本与APP_VERSION同步至0.21.0，公开协议由28升至29，SQLite保持16。Web、daemon和桌面须同步更新，web_fetch调用必须提供mode；存量会话不改写，真实数据不清理，独立联网Key须在设置中配置。
