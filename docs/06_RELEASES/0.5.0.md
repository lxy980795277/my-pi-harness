# 0.5.0

日期：2026-10-19。接入GitHub应用登录，完成M3复核与代码治理，为M4扩展能力开发提供已登录的本机工作台。当前仅本地提交，不推送或对外发布；M4.1–M4.9保留规划状态。

## 应用身份与登录

- 内部用户、外部身份和应用会话独立建模，首个成功登录的GitHub账号绑定当前profile；后续同账号恢复，其他账号不继承现有数据。
- 本机配对与应用登录分别管理，会话、模型、工作区、附件及私有SSE要求有效应用登录。退出、过期与撤销清理当前客户端私有缓存和草稿，其他客户端及已接受后台任务保留。
- 网页使用授权码、state、PKCE与回调issuer校验，并显示GitHub账号选择；Electron使用Device Flow，自动打开系统浏览器并保留手动重开入口。
- 配置由仓库根.env与显式环境管理，提供.env.example；桌面资源只提取公开Client ID，根.env及Client Secret不分发。

## 工作台交互

- 登录页复用项目与GitHub品牌，按钮内展示发起跳转和回调完成进度，禁用重复点击；失败提供取消或重试。
- 用户信息卡片向上展开设置和退出登录；退出先二次确认，取消或Esc保留身份和草稿，弹窗关闭后焦点回卡片。
- 附件原文和图片内容只由打开的预览订阅；最后一个预览关闭取消在途读取并释放缓存，元数据保持独立。

## 运行时与工程治理

- 替换计划时拒绝遗漏既有Todo关联步骤，错误不改工作状态与revision；保留合法计划审核和原Run继续执行。
- 移除无生产调用的旧压缩选择/提示词模块及未使用工具定义参数，保留实际手动和自动压缩路径。
- CI桌面打包显式使用合成公开Client ID，不依赖本机.env；同步计划审核、摘要/快照、独立重置及附件鉴权说明。

## 协议与验证

客户端与daemon同步使用wire9；SQLite schema2新增应用身份与会话记录，JSONL批格式1及私有模型codec1保持原职责。旧的仅配对状态不再获得业务访问权限，原可选昵称式登录入口移除。当前开发阶段不承诺旧API或数据格式兼容；本次提交不清理现有数据、会话或工作区文件。

登录的源码/HTTP/浏览器及打包证据见[应用登录验证](../04_FEATURES/202610161500_feature_application-login/verify.md)。本轮[M3复核与治理](../04_FEATURES/202610191506_refactor_m3-readiness-governance/verify.md)有415项源码、2项构建恢复、10个浏览器场景，以及macOS arm64打包/smoke通过；各轮检查有重叠，不合并为独立总数。提交钩子的格式、lint、typecheck和全仓源码测试以实际提交结果为准。
