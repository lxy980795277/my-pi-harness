# 0.1.0

日期：2026-10-13。首个工程版本，保留初始化时确定的0.1.0；此前Git仅有仓库初始化README，没有已提交的产品版本。

## 新增功能

### Web

- React、shadcn风格控件与Tailwind共享界面，支持浏览器和Electron入口。
- 真实健康检查、SSE实例校验、连接失败与手动重连、浅深主题。

### daemon

- 独立Node24本地服务，提供health、SSE和生产Web静态资源。
- 校验启动配置与控制消息，支持IPC关闭、父进程失联检测和连接清理。

### desktop

- Electron窗口与有限preload桥，独立Node服务监督，默认拒绝权限和未知导航。
- 装配随包Node、daemon生产依赖与Web，提供应用目录打包及真实启动smoke。

## 改进优化

### 工程规范

- pnpm/Turbo monorepo，明确应用、共享协议与构建配置职责，分开源码和产物验证。
- AGENTS与docs00–10参考Magic Book开发范式，详细规定React、Zustand、Electron、后端、安全、存储和测试。
- 采用较新受支持的兼容版本，严格peer与固定lockfile；CI actions固定正式版本的完整SHA。
- 显式提供测试与共享配置需要的catalog peer，防止自动解析越过选定的Vite/ESLint版本线。
- ESLint、可访问性、源码约定、依赖边界、文档及版本门禁，包含真实非法fixture与配置覆盖检查。

## 问题修复

### desktop

- 启动取消与重复退出等待完整资源清理；窗口关闭释放引用及桥handler。
- 约束frame导航、重定向、IPC窗口/来源/参数，默认拒绝权限检查与申请。

### daemon

- 拒绝超出PID范围的配置，禁止SSE HEAD长连接，响应背压时跳过heartbeat。
- 关闭SSE后回收不完整HTTP请求，避免退出被半个headers阻塞。

### 工程工具

- 开发启动器等待所属进程清理，并统一Windows PATH变体；Node下载缓存校验后原子发布。
