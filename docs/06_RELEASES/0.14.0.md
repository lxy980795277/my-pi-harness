# 0.14.0

日期：2026-10-30。本次为移除累计Token预算及代码治理的本地提交，不推送或对外发布；M6仍处于规划阶段。

## 子任务执行

移除累计Token额度、默认值、设置项、任务详情预算、委派参数及额度不足错误。请求并发由独立的AgentRequestScheduler管理，保留全局与祖先子树并发、排队取消和流真正结算后的释放。消息及子树Usage继续统计，上下文容量、任务数、深度、请求轮数、时限和单请求输出限制保持独立。

高累计用量后首次委派、嵌套执行和最终汇总已有受控Pi与临时存储回归；缺Usage不阻断后续请求，也不补造计量。新设置与工具参数拒绝已删除的字段，现有持久设置和任务历史按当前字段读取，原日志不重写。

## 代码治理

共用手动恢复与自动续跑的队列筛选和启动组装，保留各自失败语义；删除无消费者的类型，修正默认角色和指南中的预算、用量说明。MCP传输与任务变更通知复用protocol的既有类型和schema。

本地MCP配置入口和执行层复用execution拥有的环境变量名称规则，公开环境与秘密槽位一致校验。宿主路径、Shell及运行时启动控制变量在创建、更新和导入预览时即拒绝，执行前仍检查；保留原领域错误和NUL拒绝，不扩大执行权限。

## 规划与验证范围

保存[M6记忆与搜索方案](../04_FEATURES/202610301722_feature_m6-memory-search/spec.md)，明确用户/工作区范围、记忆确认、本地检索及请求注入设计；未实现记忆功能或预建空模块。M5移除额度和本轮治理分别由[M5验证](../04_FEATURES/202610281702_feature_m5-subagents-board/verify.md#移除累计token限制2026-10-30)及[治理记录](../04_FEATURES/202610300028_refactor_m5-code-governance/verify.md)维护实际检查与证据。

根版本与APP_VERSION同步至0.14.0，公开协议21升至22，前后端及桌面需同步更新并完整重启。SQLite schema9、Session事件envelope1和现有JSONL粒度保持，不清库、不删除会话，不改写已有失败结果。新协议不接受limits.tokenBudget。

本轮不重新生成桌面应用目录或安装器，不宣称新的真实供应商、GitHub账户授权、Electron操作、Windows、签名或公证验收；先前0.13.1实际应用目录和模型证据保留原范围。现有平台及M4外部账户/Office视觉缺口继续归原里程碑。
