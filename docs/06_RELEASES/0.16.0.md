## Agent工具与上下文

内置模型工具从34项收敛为28项，统一工具目录、主子Run初始选择和按需候选。普通macOS有工作区且启用委派的根Run默认11项，有可用Skill目录时12项；实际集合随角色、显式选择与已有工作状态变化。tool_search检索允许使用的内置与MCP候选，命中后先持久化，再从下一模型请求激活，本Run内保持可用，新顶层Run重新选择。

移除load_tools、skill_search、request_skill_tools、revoke_skill_tools、restore_context_checkpoint和reset_working_state六个模型入口，用户检查点恢复及工作状态重置API保留。删除专用Skill grant/revoke、旧停止回调与重复路由名单，实际执行继续经过统一审批和权限策略。

工具目录、选择、加载与执行各有独立拥有者。子任务继承项和候选按角色过滤，子加载不改变父或兄弟的集合；达到委派深度后仍可等待已有后代。长工具结果裁剪提供真实宿主记录ID，当前请求具备读取工具后才承诺可恢复正文，Plan/Todos及Skill资源的已知依赖在请求预算计算前加入。

## Skill与持久化

Skill摘要和正文渐进加载，模型通过load_skill({id})选择Skill，宿主校验接受时冻结的内容、来源与授权代次。正文、资源和租约由RunSkills管理；排队消息中的显式Skill在真正消费消息后加载，消费前编辑或删除不会残留待激活正文。

接受快照使用带真实来源、schema与指纹的nativeCandidates及Skill候选元数据，动态加载投影拒绝未接受或被替换的工具和绑定；初始工具定义不重复写入候选。公开协议22、SQLite schema9、完整消息落盘粒度与应用codec1保持。

旧开发日志中的workspaceCandidates和缺失Skill候选的队列元数据不再支持。本地结构检查发现两份会话含旧能力接受快照及加载事件，重启新实现前需处理；本轮未清理、改写或重建原会话及数据库，配置、工作区与授权均保持。工具分类维度和命名按用户要求留到下一迭代。
