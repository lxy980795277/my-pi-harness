# 0.4.0

日期：2026-10-16。完成M3上下文与交互的完整实现、代码治理及核心技术文档沉淀。本版本为本地源码提交，不推送或对外发布；版本号不代表M4已开发。

## 会话存储

- JSONL由公开镜像改为会话执行事实源，每行保存带校验和与顺序的完整宿主批次，包含恢复所需私有数据；HTTP/SSE仅返回公开投影。
- 完整批次先经SQLite事务校验，再追加日志并fsync，随后提交SQLite投影与发布事件。写入或投影失败冻结后续写入，重启从日志重建，不重复模型或工具副作用。
- 附件保存为独立不可变校验文件；SQLite保留Provider、工作区与应用设置，以及可重建的会话和附件索引。完整恢复需要日志、附件和对应配置，不能只复制JSONL。
- 日志继续按profile隔离放在仓库根`.my-pi-harness`；独立安装包须显式指定该目录，数据库和系统凭据仍保留原有职责。

## 上下文与工作交互

- 每次模型请求执行上下文投影，保留规则、原任务、计划及完整工具周期；分类估算与Provider Usage校准分开呈现，输出空间明确预留，超限拒绝请求。
- 同一Run支持连续结构化压缩、父子摘要版本、有界fallback和取消；上下文检查点可比较、选择，模型可有界检索当前会话原文，原始历史保留。
- 人工提问支持多题、单选、多选和自由输入；计划支持反馈、修订、批准及取消，等待用户后继续原Run。Todo关联步骤及完成依据，继承历史与新证据分别校验。
- 手动会话快照恢复创建新分支；任务重置与上下文重置分别生效，不承诺回滚文件、Shell或外部系统。
- 附件增加常见Office/开放文档文本提取、仅附件发送和图片粘贴；保留上传时校验、解析取消与历史预览，不提供OCR或原始文档编辑。

## 工程与文档

- 领域类型文件简化命名，业务联合类型集中定义，复杂空值选择和错误优先级使用明确分支。
- 替换实际弃用的React事件、Query和测试API，以标准composition事件维护输入法发送行为；ESLint增加类型感知弃用检查，源码检查约束冗余类型文件命名。
