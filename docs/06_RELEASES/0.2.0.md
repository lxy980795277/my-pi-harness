# 0.2.0

日期：2026-10-15。M0之后累计的M1模型会话、模型设置与M2工作区执行；本次为本地源码提交，不推送或对外发布。

## Runtime 与存储

- 接入Pi core/ai，支持六个内置Provider入口、自定义三种协议、API Key/OAuth协调、默认模型与会话模型选择。
- SQLite保存Session、Run、事件、队列、分支和工具结果；支持流式对话、停止、输入排队、编辑重发及重启恢复。
- 工具调用使用assistant消息锚点隔离公开ID，SDK私有调用ID保持原样；工具快照按消息锚点和持久化请求顺序排列，更新、分支与重开不改变先后，同毫秒最终回答也保持在工具后。

## 工作区与工具

- 统一工作区—会话树，显示创建时间；新对话直接输入，首次发送才创建会话。
- 文件/图片/PDF读取、目录、文本搜索、写入、精确编辑与Diff、Web GET/POST及macOS受监管Shell。
- 逐次审批与只读策略、根路径和敏感目录限制、公开网络目标检查、取消/超时/输出限额及所属进程回收。
- 桌面点击选择或拖入目录；18个Lucide工作区图标可保存，侧栏和输入栏一致展示；紧凑弹窗区分图标与文本输入焦点。

## 设置与工程

- 模型配置集中在用户卡片打开的设置Dialog，加载状态在弹窗内，滚动区域保留边缘间距。
- 四份前端、后端、Desktop、Testing规范；TSX/Hook分工、异步与组件约束、依赖边界与源码/文档门禁。
- Feature目录统一为北京时间连续12位分钟时间戳，历史目录引用迁移，后续任务须对齐roadmap。
