# 0.10.1

日期：2026-10-28。本次为M5前代码治理与技术文档整理的本地提交，不推送或对外发布。

## daemon与资源生命周期

启动失败时逐项释放所有已取得资源，单个清理失败不再跳过后续服务和profile关闭；多个错误保留原启动失败。插件授权服务的并发关闭共享同一排空结果，等待在途OAuth和凭据操作结束。

## 设置与异步状态

关闭或切换账户编辑目标时取消所属UI任务，旧保存结果不再关闭或污染新编辑器，服务器事实仍重新读取。Skill资源预览独立管理取消和错误，并绑定Skill ID、内容版本及工作区；切换目标清除旧正文，旧卸载完成也不会清除新选择。

## 工程与技术文档

补齐Web及Desktop实际使用的Vitest开发依赖，移除integrations无消费者依赖、未实现的远端fetch注入选项及Office未使用的stderr缓存，保留输出界限与进程回收。

新增插件体系和MCP连接两篇核心技术设计，替换内容重叠且有过期授权描述的旧篇；同步技术总览、架构、Runtime、工作区及daemon说明。治理范围、逐项发现与实际证据见[治理验证](../04_FEATURES/202610280040_refactor_technical-docs-governance/verify.md)。
