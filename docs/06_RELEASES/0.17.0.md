## Agent运行时

子任务实现从agents迁入subagents，SubagentCoordinator唯一拥有任务树索引、计时器、写入拥有权及停止收束。委派策略、通信、模型工具路由和Run适配分别由policy、messaging、tool-dispatch和run-adapter承担，不新增package、重复Map或转发兼容层。通用Run通过自己拥有的RunHooks和RunInjectedInput接入调度及原子消息消费，不反向依赖subagents模块。

移除主、子Run的固定16/32轮模型请求及单Run64次工具调用截断，同时删除maxTurns配置、工具参数、内部计数和设置/详情展示。任务数、递归深度、请求并发、已有时限、单次输出、上下文容量以及同时声明64个工具的容量继续独立生效。

同Run内，相同工具与完整规范化参数连续调用第3、5、8次时追加宿主提醒，不改变参数、审批或执行状态。不同工具/参数重置连续计数，动态工具集合更新保持计数，新Run独立；提醒不回显原参数，随原tool.context终态批次落盘。原内容已达128块容量时跳过提醒，保留全部原结果。工具指纹和重复检测共用tools/identity的JSON规范化。

子任务结果仅从选定Run回收正文，失败、取消或超时仍保留已有文字及真实状态/错误。partial区分未完成、模型length截断及返回文字截短，成功完整回答不标partial；空结果不借用旧续作文字，不把工具原始结果自动拼成报告，也不新增强制总结请求。
