# 0.18.0

日期：2026-11-06。属于M0架构治理及既有M2–M5工具能力维护；本地提交，不推送或对外发布。M6继续仅规划。

## 工具与沙箱

新增tools和sandbox两个私有包，移除execution包。tools按一个工具一个文件组织27个原生工具，统一声明、策略、绑定与结果处理；agent-runtime继续拥有Run、审批、工具调用事实及主子Agent调度。sandbox独立负责真实路径、网络目标、进程隔离与回收。

受管命令支持增量输出、等待和停止，保留会话/任务归属及执行租约。进程物理关闭、资源释放与写入租约结束后才能报告成功；权限撤销、取消和失败按所属生命周期清理。

## Skill与插件

插件目录与Skill资源由tools拥有，连接、OAuth及远端协议留在integrations和daemon。办公能力通过四个Skill的Python CLI执行；资源按内容冻结、校验并物化到只读执行目录，在途命令持有明确租约。旧shell、office\_\*及pdf_read_pages模型工具已移除，分别由受管命令和文档工具承担。

## 产物

通用publish_artifact替代Office专用发布接口。storage校验授权文件并保存不可变内容，daemon验证会话/任务范围后提供下载，Web主对话与子任务共用产物展示。文件大小、配额、生产命令归属及下载租约保持有界。

## 版本与验证范围

根产品版本与APP_VERSION同步为0.18.0，公开协议24、SQLite schema10。旧execution包、Office工具及接口不再提供兼容入口；旧开发数据不保证兼容，本次未清理用户数据。

验证命令、实际结果与异常记录见[功能验证](../04_FEATURES/202611041712_refactor_tools-skills-sandbox/verify.md)。已完成全workspace类型检查与构建、静态规则、聚焦主子工具/资源测试，以及隔离生产deploy中的PDF读取和四个办公Skill执行；27个工具的声明、可用性与策略对照保持一致。提交钩子的完整检查结果另记录在同一验证文档。

Windows/Linux本地进程后端未实现，macOS full-access使用宿主用户权限。未重新验收真实OAuth、全部供应商、Office视觉质量、LibreOffice转换或正式安装器、签名和公证；本地提交不代表正式发布。
