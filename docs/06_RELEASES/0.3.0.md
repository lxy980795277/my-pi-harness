# 0.3.0

日期：2026-10-15。累计M3第一轮实现、审批与JSONL优化，以及M2工作区交互调整；本次为本地源码提交，不推送或发布安装包。

## 上下文与交互

- 发现工作区和文件引用祖先的AGENTS规则，按作用域组装并冻结运行内容，展示来源及预算估算。
- 上传、预览和发送文本、图片与PDF文本，附件随消息、队列和历史持久保存；文件引用保留宿主API和历史预览，添加入口按用户要求移除。
- 完整轮次和工具配对裁剪，手动与阈值触发的模型摘要，保留历史并处理取消、失败及分支隔离。
- Agent可提出选项或自由回答问题；Plan/Todos可编辑、批准并持久保存，Plan模式禁止修改文件和命令执行。
- 检查点支持比较、保留原分支的恢复及工作状态重置，不回滚磁盘文件、Shell或外部请求。

## 审批与日志

- 权限提供请求批准、独立AI帮我批准、完全访问三种策略；旧只读记录继续有效，AI复核失败或结论不明确时转人工。
- 完全访问由用户明确选择，macOS Shell使用当前用户权限执行；Plan限制、超时和所属进程组回收继续有效。
- SQLite事务提交后同步每会话公开JSONL镜像，启动补齐已有历史及不完整末行；镜像写入失败明确报告数据库已提交并暂停后续持久写入。
- 开发和正式运行统一使用仓库根的`.my-pi-harness/`，按profile路径摘要隔离。独立安装包须显式配置`MY_PI_HARNESS_SESSION_LOG_ROOT`指向该仓库目录；数据库和系统凭据保留原位置，旧日志不删除。

## 工作区体验

- 侧栏整行即时hover，右侧悬浮更多与加号；目录标题只展开/收起，加号明确进入预选工作区的新对话，发送前不创建空会话。
- 更多菜单提供重命名和删除；下拉统一从触发器下方开始边对齐并保留视口避让。
- 目录容器中央按钮触发选择，空白区域只接收拖放；工作区选项仅图标和名称，移除路径tooltip。
- 共享Select关闭回焦不增加边框或光圈，输入容器只响应文本输入聚焦。添加上下文菜单为上传文件及禁用的MCP/Skill占位。

## 兼容与验证

wire从5升级至7，客户端与daemon须同步更新。SQLite追加迁移0005，旧事件和迁移1–4不重写；Session信封仍1，私有codec继续写2并读取1与2。不承诺旧应用读取升级后的数据库，回退前应保留兼容备份。

JSONL仅保存公开事件，不含私有模型codec、凭据或附件字节，不提供独立完整恢复或导入。路径配置与失败处理见[架构](../01_ARCHITECTURE/overview.md)和[存储说明](../../packages/storage/README.md#会话jsonl镜像)。

已有源码、构建daemon、浏览器和截图证据分别见[M3验证](../04_FEATURES/202610151655_feature_m3-context-interaction/verify.md)、[审批与日志验证](../04_FEATURES/202610151800_feature_approval-session-jsonl/verify.md)、[工作区导航验证](../04_FEATURES/202610151400_refactor_workspace-navigation/verify.md)。这些行为证据主要在0.2.1源码版本上执行；本次升版同步APP_VERSION，正常提交钩子执行最终lint、类型与源码检查，结果以提交记录为准。

原M3桌面smoke覆盖wire6的macOS arm64未签名目录包；最新wire7、仓库日志根及后续UI尚未重新打包验收，不将旧包作为0.3.0证据。Windows Shell/实机、浏览器新增目录仍按用户决定留在M2；真实供应商与账号、正式安装器、签名、公证及自动更新未验收。MCP/Skills实际能力仍属M4，本次只有入口占位。

M3已有一轮实现；下一轮按原M3.1–M3.8进行用户体验验收和必要补漏，任务顺序见[M3 Spec](../04_FEATURES/202610151655_feature_m3-context-interaction/spec.md#待确认的模块验收顺序)，确认前不追加功能开发。
