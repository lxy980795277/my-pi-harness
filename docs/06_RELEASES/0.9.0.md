# 0.9.0

日期：2026-10-27。本次为M4能力收尾的本地提交，不推送或对外发布。

## 插件与授权

- 插件详情以授权/已连接状态管理GitHub、Google等服务连接，点击授权打开独立窗口，完成OAuth授权码与PKCE流程；主窗口轮询连接状态，桌面端通过一次性ticket在系统浏览器启动授权。
- OAuth客户端按插件独立配置，与应用登录和高级手动账户分开。凭据只存本机`skill-credentials.json`，文件权限为0600，Skill只读网关与插件MCP Apps复用同一份凭据；前端、模型及会话日志不接收Token。
- 内置资源在启动时自动对账，插件详情与安装后的Skill正文一致，App目标统一来自随包`.app.json`。保留插件整体与组件独立开关，授权状态和MCP目录状态分别展示。

## MCP与工具发现

- 授权MCP目录支持后台预热、持久快照及重启恢复；恢复时重新核对配置、身份、工作区、信任和凭据版本。单服务失败保留独立诊断，准备、取消和关闭覆盖实际异步操作的生命周期。
- `tool_search`使用MiniSearch词法检索与本机CPU语义向量融合，搜索结果自动暂存，并在下一次模型请求前记录工具加载事实；语义准备超时可使用词法结果。保留精确名称`load_tools`及每次执行的审批和持久化屏障。
- 启用Skill摘要、显式提及及服务诊断进入可重建上下文；已加载正文跨Run、队列及压缩保留，并遵守分支可见前缀和上下文重置。停用或重新安装后失效的旧绑定不继承，显式选择继续校验。

## Documents与PDF

- Documents补充页面、字体、富文本、页眉页脚、页码、图片及修订能力；PDF补充流式排版、自动分页、长表格、页眉页脚及选择表单读写，保留固定页面模式。
- 随包工作流提供分任务Skill及参考资源，动态加载Documents/PDF Skill时同步加载已冻结的本地Office工具。Python执行沿用统一策略，不隐式安装依赖；下载继续校验输出内容哈希。
- 清理已由启动对账取代的人工同步API、旧账户桥接和固定REST工具目录，以及重复状态、无消费者schema和类型转导出。
