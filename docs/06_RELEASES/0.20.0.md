# 0.20.0

日期：2026-11-12。完成M6长期记忆与历史检索、相关代码治理及本机入口修复，按用户授权本地提交，不推送或对外发布。M7与既有平台、账号及办公质量验收缺口继续保留。

## 记忆与历史检索

新增独立memory领域包，支持当前用户与工作区的长期记忆、固定或相关采用、编辑、停用、遗忘和有效画像。明确要求记住或纠正时直接保存；默认从对话学习稳定偏好和事实，使用与学习开关由宿主执行时复核。Agent写入核对人类来源、scope、revision和幂等身份，删除遵守会话审批策略。设置中可查看和管理原记忆，历史请求保留当时实际采用的内容。

持久历史与记忆共用本地FTS和embedding混合检索，相关记忆通过独立本地复核模型决定是否自动采用。模型准备由用户显式触发，查询和GET不自动下载；资源队列、取消、离线恢复与关闭由所属服务管理，工具目录检索复用本地模型资源。

Web提供范围与时间筛选、结果原文、消息/长文本分页、历史虚拟定位和待发引用。引用冻结来源身份、版本及选区，保留草稿，不切换执行分支；Agent的历史读取与引用检查复用持久原文。主子请求派发前复核记忆，等待名额期间的编辑、遗忘或设置变化会使请求重新准备，避免派发过期内容。

## 运行时与代码治理

请求准备统一持有上下文和记忆快照，取消信号由调用上下文拥有。记忆召回复用SearchService的查询和关闭生命周期，工具检索适配器与模型资源各司其职；来源身份比较归共享纯函数，范围与权限仍由宿主执行。清理未使用接口、重复校验和前端状态，分页使用互斥状态表达消息与文本位置，向量持久读取继续拒绝损坏数据。

记忆保存、更新或遗忘后，已打开的记忆搜索结果同步刷新；取消的旧请求不能恢复旧正文，对话历史查询与原请求采用记录保持。

## Web与桌面入口

移除手工配对页面、生成入口、终端挑战和配对接口。浏览器通过受Host/Origin校验的POST自动初始化低权限客户端，再进入GitHub应用登录；有效客户端与应用会话正常复用。Cookie、CSRF、profile账号归属、撤销及私有API/SSE校验保留，桌面启动secret继续仅由main与daemon持有。

daemon统一解析profile，桌面不再使用Electron userData覆盖业务数据路径。macOS默认沿用已有桌面命名空间`~/Library/Application Support/@my-pi-harness/desktop/profiles/default`，Windows保留LocalAppData规则；显式profile配置两种入口一致生效。Cookie和缓存独立于业务profile，smoke显式配置临时业务目录。已有桌面数据库、JSONL与系统凭据命名空间不迁移，不自动合并另一套旧profile；同时打开两个前端时连接同一个daemon，排他锁保持。
