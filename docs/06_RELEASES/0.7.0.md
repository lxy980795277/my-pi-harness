# 0.7.0

日期：2026-10-26。本次为M4累计迭代的本地提交，不推送或对外发布。

## 运行时与扩展

- MCP支持受监管stdio、Streamable HTTP及SSE、独立启动信任、静态凭据和OAuth；提供工具目录、按需加载、逐工具策略、配置导入与脱敏导出。
- Run冻结工具定义、来源和授权；动态工具与Skill加载进入会话事实，模型请求、预算与执行路由保持一致。可能已派发的调用保留unknown，恢复及取消不自动重放副作用。
- Skills支持发现、显式选择、渐进加载、创建、安装、启停和卸载，冻结正文及资源并保持压缩连续性；九个内置插件提供市场和组件管理，停用与卸载撤销所属能力。
- GitHub、Google、Vercel、Notion、Supabase连接提供账户管理、受限REST操作与MCP凭据共享；账户授权不等同每个Run的使用授权。

## 办公与桌面

- 本地办公工具支持DOCX、XLSX、PPTX、PDF的创建和受控修改、结构检查、PDF页图及受保护的产物下载；独立资源和Python依赖检测随宿主部署。
- Electron有限桥支持扩展授权流程，随包daemon装配新增依赖与资源；关闭和撤销收束所属连接及进程。

## 前端交互

- 首屏登录校验、服务协议检查及必要数据获取共用一个加载界面，完成后展示工作台；后台刷新保留页面与草稿。固定光环显示彩色流光，文字后跟随跳动圆点，尊重减少动态效果设置。
- MCP主入口采用表单/JSON双Tab，提供MCP ID、HTTP/SSE、Header配置及真实连接测试；本地进程和批量交换置于高级配置。秘密不进入Query、Zustand或导出。
- MCP和Skill选择贯通发送、排队与历史编辑；新对话默认完全访问权限，已有会话保留自身策略。
- 发送和终止按钮共用一个位置，运行中仍支持Enter排队；待回答问题随对话主区域滚动，移除其嵌套滚动容器。折叠工具行改为12px及更轻的文字和图标。
