# 0.8.0

日期：2026-10-26。本次为插件市场交互迭代的本地提交，不推送或对外发布。

## 插件市场

- 市场按图标、名称和简介展示插件；安装后以Switch控制整体启停，保留独立卸载，不在列表下方展开组件或状态容器。
- 设置内容区提供市场、插件详情和Skill详情三级导航。插件详情分组列出应用和Skills，保留MCP状态及连接管理；Skill详情只读渲染Markdown正文，支持独立启停和逐级返回。
- 未安装或停用的插件仍可预览随包Skill内容。分类在返回时保留，页面切换复位滚动及键盘焦点；启停状态来自服务端并随刷新持久保留。整体停用保留组件偏好，禁用项仍保留在Skills管理目录。
- 插件图标使用现有本地品牌资产或办公语义图标，浅深主题均可用；配置读取失败明确显示失败，卸载按钮使用成对错误主题色。

## 详情接口与协议

- 新增受保护只读 `GET /api/plugins/:id`，仅从有限内置manifest指定的位置读取SKILL.md，返回插件状态、Skill简介与正文；保留文件、链接、UTF-8、大小、取消和关闭检查。
- 预览不安装插件、不创建Skill快照、不读取凭据或授予Run权限。安装、整体和组件启停、卸载沿用现有revision及归属检查。
- 产品版本和APP_VERSION为0.8.0，内部私有包保持0.0.0。通信协议15要求Web、Electron与daemon同步更新；SQLite schema 6、JSONL批次2及公开事件envelope 1均不变，无新增数据迁移。
