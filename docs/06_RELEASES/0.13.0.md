# 0.13.0

日期：2026-10-30。本次为M5子Agent与任务看板、会话持久化精简及代码治理的本地提交，不推送或对外发布。M5工程实现与本机自动化验证完成，用户体验、真实供应商及桌面平台验收仍待完成；M6未开始。

## 子Agent执行与权限

主Agent支持委派、查询、等待、通信和停止，子任务拥有独立上下文、工作状态和稳定Task身份，每次执行由原RunExecution承担。支持并行、嵌套、显式续作、角色与预算限制；通信先持久化再消费，父任务结束前结算后代，重启不自动重跑模型或外部副作用。

子Run继承父Run冻结的审批策略，角色能力独立收窄。完全访问下只读角色的正常网页GET不再额外请求批准，ask及auto仍分别走人工批准和独立模型复核；写入、Shell、POST与动态MCP/Skill继续受角色、精确授权和工作区规则限制。工具集重建统一归一化，避免重复计算旧指纹导致已加载工具被拒绝。

## 任务与对话界面

新增任务看板、会话任务入口、任务树、分页详情及角色预算设置。子任务中的提问、计划审核及工具审批保留原Task/Run归属；关闭详情保留未提交草稿，未知提交结果保留完整请求身份，手动重试不重复创建执行。Work和任务订阅保留在途失效通知，补刷最后状态。

思考与工具摘要共用轻量行，生成等待统一为三个跳动点。请求错误显示在对应回答或任务中，保留部分正文与历史归属；移除顶部重复错误横条，修复短历史刷新后首行不可达。子任务生成的Office产物可在当前可见分支下载，跨会话、已裁剪委派和不符合路径/摘要约束的文件仍拒绝。

## 会话持久化与代码治理

文本和思考增量只更新进程内覆盖层，完整消息在正常完成、取消或失败时持久化，不再逐token写JSONL及SQLite事务。snapshotSeq与liveRevision分别表示持久及实时变化，HTTP/SSE按双水位同步；真正崩溃前尚未完成的内存片段不恢复。工具审批、派发、结果和必要模型恢复事实仍落盘。

任务详情按SQL范围分页，仅解码本页正文与相关工具，用量聚合限定目标子树；删除无消费者的messagesQueue公开字段。请求上下文基线按Run及分支拥有，子Run结束不再清除父/兄弟基线而重复记录完整历史。准备阶段超时与真实故障保留失败原因，主动停止单独记录取消；清理冗余字段、重复逻辑和过期文档。ESLint入口单独设置8GiB堆上限，保留全部检查规则及扫描范围。
