# 桌面治理

先读 [Electron/PC约束](../05_CONSTRAINTS/desktop.md)、[架构](../01_ARCHITECTURE/overview.md) 与发布范围。审查main、preload、daemon监督和开发/发布脚本，不能只查看BrowserWindow安全布尔值。

- 页面地址与资源解析受控，开发覆盖不进入生产；导航、重定向和新窗口均有拒绝路径。
- session同时处理权限检查和申请；来源不可信、另一窗口及子frame无法取得桥能力。
- preload只公开固定DTO方法，无任意channel、路径、Electron对象或环境泄露。
- 启动等待可取消且有界；启动未完成时退出、重复退出、页面加载失败都回收已拥有资源。
- 独立Node和依赖从安装资源加载；原生模块宿主、平台与架构匹配，不依赖用户PATH或源码。
- IPC关闭、父进程失联、异常退出和开发进程树结束有实际完成证据。
- Windows磁盘路径、env大小写和终止策略单独检查；POSIX成功不能替代Windows结论。
- 包资源链接不外逃、缓存无半成品、根应用版本一致；签名与公证状态如实说明。
- 打包smoke在临时cwd和数据目录执行，证明有限桥、安全拒绝、服务就绪与所属PID消失。

治理发现与修复分别记录。未执行目标平台或系统操作使用“未验证”，不要把mock过的main配置和本机截图作为正式安装证据。
