# 设计语言

产品是供用户长期工作的PC Agent界面。沿用参考范式的克制、秩序和信息可读性，用语义token和统一组件表达状态；具体页面布局与已确认视觉决定写在所属功能Spec，不搬用参考产品的固定字号或业务面板。

## 视觉与组件

- 控件优先shadcn/ui，业务通过统一的components/ui入口使用；同类按钮、输入、菜单、Dialog和Badge保留一致尺寸、焦点与禁用状态。
- 颜色只用于实际语义、焦点和主要操作，背景层次用明确的surface token；文本与背景成对使用foreground，不能只替换背景造成低对比度。
- 颜色、圆角、间距和阴影由共享主题token管理，不在页面复制原始色值。token依据实际页面集中更新，避免为了单个页面创建第二套主题。
- 常规间距使用一致尺度，允许布局尺寸按真实阅读和窗口需求决定；不机械移植旧产品11px全局文字、等宽字体或取消outline规则。
- 图标辅助文字，采用统一库与尺寸；装饰图标不重复朗读，只有图标的操作提供可访问名称。实现细则见 [前端约束](../05_CONSTRAINTS/frontend.md)。
- 标题、字段标签和控件已经表达的操作不再重复写说明。补充文案只承载必要条件、权限、操作后果或恢复办法；无额外说明的Dialog不添加空描述或重复的隐藏文案。

## 布局与可访问性

明确窗口、页面和各面板的滚动所有者，长消息、代码、工具输出与错误不撑破布局。PC常见窗口尺寸可完成主要操作；字号缩放和窄窗口时不得让必需按钮消失。复杂列表按真实规模选择虚拟化，不将信息密度等同于更小文字。

键盘可访问主要流程，焦点可见；Dialog进入后管理焦点，关闭回到触发者。禁用、loading、错误和成功同时使用文字或符号，不仅靠颜色。动效用于响应反馈并尊重prefers-reduced-motion，不能阻碍长时间阅读。

Select聚焦采用轻微背景反馈，选择后自动回焦不增加边框或光圈；对话输入容器仅响应文本输入的聚焦，底部工具栏操作不改变外框。

下拉面板默认在触发器下方开始边对齐，向右展开，靠近视口边缘时自动避让。工作区选择项只显示目录图标和名称，悬停及键盘聚焦不展示路径提示。

## Agent状态

连接状态由真实health/SSE决定，Agent和工具状态由实际事件决定。区分连接中、断线、运行、等待审批、取消、失败、结果未知和完成；不把绿色服务状态误呈现为Agent正在执行。

危险操作展示目标、范围和后果；审批决定和执行结果分别呈现。错误说明可采取的操作，不向普通用户展示内部堆栈；重连、重试、恢复和undo只有在实际支持时显示。

主页面采用最左侧导航与工作区—会话树；不建立第二条会话侧栏。初始页为欢迎文案和居中输入框，首次发送才创建会话；进入对话后，同一输入控件固定在时间线底部。工具栏依次为上下文加号、工作区、审批策略、模型/思考等级和发送，尚未实现的上下文加号明确禁用。工作区行可展开，对话显示创建时间；底部用户信息卡片向上打开紧凑菜单，依次提供带图标的“设置”和红色“退出登录”。设置与退出确认弹窗接管焦点，关闭后回到信息卡片；退出确认使用警示图标、简短后果说明，默认聚焦取消，确认按钮使用实心危险色。

登录发起、网页跳转和回调完成沿用同一品牌卡片，以禁用的GitHub按钮展示进度，避免切换成空面板；失败后才展示相应恢复操作。设备码授权仍显示验证码与等待状态。

工作区默认按展开状态显示蓝色打开/关闭文件夹，标题行悬停或标题按钮键盘focus-visible时在同一16px位置替换成展开/收起箭头；鼠标移出后恢复文件夹，不因点击保留的普通焦点持续显示箭头。会话背景占满侧栏列表可用宽度，内部左侧padding使标题与目录名称起点对齐，目录和会话行高统一32px。

工作区标题只展开/收起，右侧绝对定位“更多”和“加号”，hover即时显示且不占主按钮布局宽度；目录和会话条目不使用hover过渡动画。更多中提供重命名、删除；加号明确进入新对话并预选该工作区，不提前生成空会话。菜单打开或键盘聚焦期间保持操作可见，长标题截断后不覆盖操作。

自定义工作区图标复用同一尺寸与颜色规则，悬停仍替换为展开箭头。添加弹窗将图标选择按钮与名称合为一行，下方仅保留目录选择区；目录路径只读，中央按钮点击选择，容器空白仅接收拖拽。图标面板仅使用固定Lucide图标，支持搜索与重置，不提供颜色或emoji。具体交互见[工作区选择Spec](../04_FEATURES/202610151534_feature_workspace-creation/spec.md)。

正文与输入区保持有限阅读宽度，surface、圆角与留白一致；普通输入不嵌套大量Card，不把会话名称、运行配置表单放在初始页。工具活动采用时间线卡片，参数、Diff与结果可展开；待审批动作和完成状态明确分开。

M2交互和能力见[工作区与执行Spec](../04_FEATURES/202610150930_feature_workspace-execution/spec.md)。操作见[用户指南](../07_USER_GUIDE/model-session.md)。工程底座布局见 [M0 Spec](../04_FEATURES/202610130900_feature_project-foundation/spec.md)。新业务组件的变体、状态与数据输入在真正实现时记录，避免预建一套没有调用方的设计组件。
