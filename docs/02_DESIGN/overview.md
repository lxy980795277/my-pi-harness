# 界面与交互

Web 和 Electron 共用 React 界面，使用 shadcn/ui 与 Tailwind CSS。基础交互优先复用同一套组件和语义 token；不因运行于桌面窗口创建第二套产品页面。

视觉、组件与可访问性原则见 [设计语言](design-language.md)，前端写法由前端约束负责；新业务组件在所属Spec中定义实际状态和变体。

M0 页面显示本机服务状态和版本信息。连接中、连接成功、连接失败和断线重连必须可区分；没有 Agent 能力时不呈现假的会话、工具结果或成功执行记录。页面的实际验证由 [M0 Spec](../04_FEATURES/20261013_feature_project-foundation/spec.md) 承担。

## 前端数据职责

组件负责呈现，数据访问经过 feature的API或共享客户端。服务数据、连接状态与纯UI状态分别由其所有者维护，避免将同一服务事实复制成多个可写状态源。流式更新批量呈现，长列表在需要时采用虚拟滚动。

后续功能在对应 Spec 中记录页面布局、正常及异常交互；本页保存稳定设计规则，不提前规定尚无实现依据的页面细节。
