# 本地MCP宿主

`McpService`拥有本地Server配置用例、系统秘密槽位、按隔离范围记录的启动授权和工具目录缓存。持久配置通过`ProfileStore.mcp`写入SQLite，秘密字节通过独立系统凭据ref保存；响应逐字段组成安全DTO，不返回ref、秘密、协议原文或异常cause。管理HTTP沿用统一登录、Origin与CSRF保护，路径见[管理协议](../../../../../docs/04_FEATURES/202610201932_feature_m4-capabilities/local-mcp-contracts.md#8-管理api与界面)。

GET列表、详情和缓存工具目录不启动进程或网络连接。用户明确预览后，trust重新解析有效程序、显式文件入口、工作根和环境指纹；保存匹配revision/accessEpoch的作用域授权并启用。sandboxed与full-access分别确认。发现与测试使用短租约，结束即关闭；已启用、已信任的目录也可由受管准备任务初始化，不能将GET当作发现入口。

`CatalogCache`拥有内存目录、SQLite派生快照、最多四路并发准备、三十秒取消截止与逐目录单飞任务；本地程序检查也在同一任务内，不可中断的文件读取在取消后仍由关闭操作等待，完成后不得启动协议连接。`RemoteCatalogs`在应用完成插件装配后后台预热；Run接受等待同一个任务，不能在准备中将空目录当成最终结果。某个Server失败不会阻止其他目录或普通聊天，安全`diagnostics()`快照记录idle/loading/ready/error、工具数与固定错误，供公开状态和模型上下文使用；本地快照只包括当前Run工作区与审批隔离范围。外部异常正文、认证字节和cause不进入该快照。

插件App开关通过`schedulePluginApp`加入远程目录准备，授权完成和Run冻结复用该准备任务。后台失败诊断由`RemoteMcpServiceOptions.onBackgroundError`提供，配置或授权失效统一取消OAuth流程和对应目录准备。

目录快照绑定配置revision/accessEpoch、启动授权、profile身份及秘密引用/连接授权epoch。恢复先通过官方MCP schema校验原始定义，再重新编译TypeBox；本地作用域还核对当前程序、工作根和环境身份。`LocalPreflights`统一拥有绑定冻结、复核和调用前的本地文件检查，取消与三十秒截止只结束调用方等待，实际检查仍由关闭操作收束。候选冻结中的单个本地Server检查失败会留下安全诊断并排除该Server，不阻断其他Server或普通聊天。损坏目录按派生数据删除并重新发现，不恢复旧授权。停用Server、撤销、配置或凭据变化取消过期准备并移除相应快照，迟到结果在发布前再次核对权限。单个Run取消仅停止它的等待，后台或其他Run共享的准备继续由服务拥有；服务关闭会取消并等待实际任务收束，已完成且仍有效的派生快照保留供下次恢复。

普通配置和秘密轮换拒绝活动租约，写入新ref后CAS保存，冲突或写入失败回滚新ref。停用、撤销和凭据删除先持久封禁旧授权，再回收连接；重新信任不会复活原Run或队列绑定。浏览器退出登录保留profile级授权和已接受Run；显式profile身份撤销使用独立identity epoch。

`ExternalTools`适配接受输入时冻结的定义与非秘密授权。队列恢复先核对原授权，再从持久JSON schema恢复真实TypeBox元信息，不启动Server或重绑最新选择。实际调用取得新租约后核对完整工具定义指纹，在runtime派发屏障前后再次校验授权；审批、JSONL调用事实与unknown停止策略由agent-runtime拥有，连接和真实进程由integrations/execution拥有。

服务关闭先拒绝新操作，由应用服务停止Run并结算结果，然后等待MCP连接关闭，最后关闭模型与存储。当前stdio正向验收限macOS；其他平台明确不提供受监管本地MCP执行。
