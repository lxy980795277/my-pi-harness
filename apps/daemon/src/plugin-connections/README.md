# 插件授权宿主接口

插件声明、授权码流程的生命周期、刷新、撤销与网关访问规则由[plugins包](../../../../packages/plugins/README.md)拥有；通用OAuth协议由integrations实现。本目录保留HTTP启动/回调/状态/撤销/网关路由，以及存储和异常到安全响应的映射。

根配置提供专用MY*PI_HARNESS_SKILL*\*客户端，服务装配注入PluginCredentialStore、身份与安装查询、实际监听来源及MCP失效通知。凭据不返回Renderer，插件授权不复用应用登录Token。浏览器同步打开启动页，桌面使用受保护的一次性ticket，回调成功后由主窗口轮询脱敏状态。

callback失败只返回有限阶段、原因和固定提示；未知错误和供应商正文不进入结果页。网关路由验证应用身份、内部访问令牌和插件开启状态，再调用固定来源的只读转发；插件Token只附加到宿主校验后的上游请求。
