# 插件宿主适配

插件声明、资源、安装/启停/更新/卸载与操作收束由[plugins包](../../../../packages/plugins/README.md)拥有。此目录保留HTTP管理路由和MCP App宿主适配；不保存第二份插件目录、端点表或生命周期实现。

apps.ts将插件的精确组件身份绑定到RemoteMcpService。启动对账按拥有者修复缺失配置与目标，不接管手动Server，也不恢复已撤销的信任。显式App开关由当前用户操作授予或撤销启动信任；后台发现、目录错误与重试由MCP模块拥有。路由只做输入校验、身份与请求生命周期处理，然后调用注入的PluginService。
